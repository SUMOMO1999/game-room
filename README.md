# 棋牌室

和朋友随时约一局的 Web 棋牌室。通过房间号或邀请链接加入，可以玩拉密、双人翻棋军棋、飞行棋、经典你画我猜、两副牌414、幽街商人及PARKS国家公园。七款均提供本机练习。手机可添加到主屏幕，在独立窗口中使用；牌桌以横屏为主，军棋同时支持竖屏，绘画画布按可用空间适配。

[正式入口](https://game.sumomoli.com/) · [练习大厅](https://game.sumomoli.com/practice-hub.html) · [Agora 入口](https://agora.sumomoli.com/game/) · [设计文档](docs/design/README.md) · [参与设计](CONTRIBUTING.md)

这是持续开发的项目。仓库供朋友共同设计、维护者开发使用。公开内容包含应用代码、测试和产品设计，不包含线上用户数据、密钥或运维记录。`main` 是开发主线，线上部署独立验收；提交到 GitHub 不会自动更新正式服务。正式发布使用独立冻结的运行包，账号接入改动须另行联合验收。

## 可以玩什么

- **拉密：2～7 人。** 默认 2～4 人使用两副数字牌和两张普通鬼牌，5～7 人使用三副数字牌和三张普通鬼牌。支持首次 30 点、桌面重组、四种鬼牌及开局前数量设置；每类鬼牌采用独立图案，并保留类型文字。资源与生成记录见[四类鬼牌](docs/assets/jokers-v2.md)。
- **军棋：双人翻棋。** 棋子随机扣放、轮流翻开。朋友规则允许明棋碰暗棋；夺旗后需要运回大本营，工兵全灭后有最低官阶接替运输和牺牲排雷规则。
- **七款本机练习。** 拉密有基础和鬼牌课程；军棋有只使用公开棋子信息的自动对手；飞行棋有教学局面与本机轮流练习；你画我猜可自由练画；414可以和2～7位电脑完成整局，提供选牌提示；幽街商人可与1～5位电脑完成经营对局；PARKS有普通电脑、官方单人及12课教学，全部原盒模式可配置。两款均支持全量图鉴和本机存档恢复。练习进度保存在本机浏览器，不占朋友房间，也不记账号战绩。
- **飞行棋：2～4 人。** 六点起飞、逐架跳飞、精确归航；正式大厅可开房、观战、聊天、暂停及退出。本机轮流练习另有六个固定教学局面，保存骰面和阶段；没有机器人。两个正式入口均可进入。

- **你画我猜：经典模式。** 每题一位画者，其他玩家同时猜。画者独占画笔，其他人可实时看画；选词与答案按角色隔离。支持共编分类词库、发布版本、修改记录与恢复，房间冻结本局内容；本机练画不计分。
- **414：两副牌，3～8 人。** 108张牌、逆时针出牌、多张炸弹及三档火箭，勾叉交替最多八张。支持最多8位观众、共通聊天与设置、永久娱乐积分；观众可看全部已发手牌，玩家只能看自己。普通回合不限时，勾叉响应为5秒。

- **幽街商人：2～6人。** 51种110张卡牌，六类公共货物、个人商铺和道具。逐张看牌与用牌共用每回合1～10步（默认5步），每类公共货物默认8件、开局可调4～20件；回合末60两触发收市并补完本轮。配对牌明确选目标，反制仅限受影响者，拍卖按席位轮序；支持观战、暂停、公开行动记录和1～5名电脑练习。三人以上主动退出会取消整局，无胜者。桌面使用横屏，竖屏仍可设置和退出。

- **PARKS 国家公园：标准2～5人，另有官方单人。** 第二版共春夏秋三季，每次向前移动一名徒步者，处理天气与地点、装备／水壶、预订或游览公园和拍照，最后合计六项原生分数。露营、双人Teddy、官方单人及全部9志愿项目同批交付，开局可配0～4项目和热忱二选一；最多8位观众。确认前可重选／取消，实际随机和已付费用按同局恢复，单人按徒步评级，不造击败Teddy的胜负。

完整玩法见上面的各游戏设计。规则按版本保存，正在进行的旧局不会因更新被悄悄改变。正式入口已开放两副牌414与幽街商人，PARKS亦已在两个正式入口开放；幽街2～6人规则与真实本地HTTP/SSE、旧局恢复、两正式入口的匿名电脑练习已验证，真实账号整局及手机真机仍待伙伴反馈。麻将、其他牌类和大富翁保留扩展方向，它们目前都不是可玩的实现，也不会把新文件放入仓库就自动启用。

## 房间与游戏体验

七款使用六种共通主题，统一桌面、按钮、文字和阅读层，设备本地记忆，保留棋牌及笔迹语义；不新增收费素材服务。可在游戏“设置”中选择。

2026-10-11已联合上线六款的对象移动与就地反馈：拉密摸牌／草稿确认、军棋翻面／战斗、飞行棋路线／撞回、414发牌／公共出牌、绘画一步工具／猜中反馈，以及幽街桌面读牌／材料／回应／拍卖。声音与确认动作对应，减少动态、后台与退出会清理动效。固定包`750b53a83e68c02d06d1`通过完整Linux2963项和两正式入口各196公开资源、16条实际练习操作及刷新恢复；覆盖边界见[整改计划](docs/plans/gameplay-experience-v1.md)。真机、安装PWA及主观声音听感仍需实际使用反馈。

PARKS把徒步移动、领取卡牌、新水填壶、骰子、拍照与天气变化接到实际已确认事件；每一步就地显示完整效果、代价及取消，动画不驱动业务，减少动态／后台／退出会清理。

各游戏房间主屏保留回合操作、聊天和退出；音效、规则与练习安排统一收进“设置”，开合不改变对局。本机练习没有联网聊天。

邀请、准备、房主开局、观战、退出本局、再来一局和房间清理使用共同的房间系统，暂停等能力按玩法提供。等待期间可以选择玩家或观众；开局后新加入的成员自动观战。聊天、消息气泡、回合提示、分类音效及个人战绩也由共通模块提供。

拉密支持拖动单牌、整组移动、拼接与拆分、桌面整理和自由摆放手牌。桌上牌变多时尽量缩放显示全桌，并提供放大查看；横竖屏切换会按可用空间重新呈现。对手尚未确认的桌面操作作为短时预览显示，正式牌面只有在服务端确认后才保存。

拉密、军棋和飞行棋新局每人回合 30 分钟：超时拉密摸牌，军棋跳过，飞行棋弃未使用骰面并换手，保留已确认移动。离开页面与明确退出房间含义不同；关闭页面不会直接销毁牌局，明确退房则释放席位，上述三款进行中退房会中止本局且不记输赢，全员离开后关闭房间。暂停需要在席玩家同意，保存最多七天。

414正式房间不提供暂停；进行中主动退出向其余参赛者每人赔5分。短暂重连保留席位和手牌；连续失联120秒或服务器重启会零分取消未完成局，已结算的永久积分保留。414本机练习则在弹窗或后台自动暂停、可刷新继续，不计正式积分。

正式环境复用 Agora 统一身份，棋牌使用自己的登录客户端和服务端会话。身份按 `issuer + sub` 识别，昵称只供显示；房主、席位、回合和私有手牌仍由棋牌室判断。退出棋牌室只退出本项目。股票项目保持独立。

## 本机运行（开发者）

需要 **Node.js 22.23.2 或以上**、npm、Python 3 和 `tar`。Python 与 `tar` 用于发布包校验；Node 22 的 SQLite 接口可能显示 experimental 提示。

```bash
git clone https://github.com/SUMOMO1999/game-room.git
cd game-room
npm ci --ignore-scripts
npm start
```

打开 <http://127.0.0.1:4177/>。这是仅绑定本机的匿名开发预览，房间保存在内存，重启会失去房间。第一次预览不要复制生产 `.env.example` 到 `.env`：生产模板不会提供可用的本机登录配置。

本机练习入口为 `/practice.html`、`/army-practice.html`、`/flying-practice.html`、`/drawing-practice.html`、`/poker414-practice.html`、`/hyakki-practice.html` 和 `/parks-practice.html`；PARKS另有 `/parks-tutorial.html` 与 `/parks-catalog.html`，大厅提供对应入口。需要验证登录、席位和持久化流程时，使用隔离的虚构身份预览：

```bash
npm run preview:identity
```

打开 <http://127.0.0.1:4187/>。它不连接真实 Agora 或日历账号，本机档案、会话、席位和已确认牌局保存在 `.local/` 的加密 SQLite 中；该目录及密钥不应提交。私有手牌按当前虚构身份投影，不能把此模式当作正式认证。更多运行边界见 [开发与验证](docs/development.md)。 PARKS默认关闭新建；验证其本地朋友房时用 `GAME_ROOM_PARKS_ENABLED=1 npm run preview:identity`，仅影响此次回环预览。

414 另有仅供布局与操作检查的本机小样：

```bash
node scripts/poker414-preview.mjs --port=4371
```

打开 <http://127.0.0.1:4371/>，从说明页进入。全部身份、牌局、分数和聊天都是合成数据；退出后回说明页，不进入正式大厅，也不能和朋友线上组局。当前实现与下一步见[414实施计划](docs/plans/poker414-2-v1.md#11-当前进度与待冻结项)。

## 验证（开发者）

```bash
npm test
```

测试使用虚构身份、临时数据和本机端口。入口会从当前源码生成临时运行包并校验，不依赖私人发布记录，也不连接真实账号或 AWS。没有配置 Caddy 时，两项 HTTPS 代理测试会明确跳过，其余测试正常执行。

完整发布验证还需要从 [Caddy 官方发行版](https://github.com/caddyserver/caddy/releases)取得本平台二进制，并用官方校验值固定它；同时需要支持 `req -addext` 的 OpenSSL：

```bash
GAME_ROOM_TEST_CADDY=/absolute/path/to/caddy \
GAME_ROOM_TEST_CADDY_SHA256='填入本平台官方 SHA-256' \
npm run test:release
```

`test:release` 要求所有测试通过、零跳过，并在独立解包目录按锁文件安装运行依赖。它不会下载 Caddy、安装系统证书或部署服务器。若系统 OpenSSL 不支持所需参数，可通过 `OPENSSL_TEST_BINARY` 指定兼容二进制。

自动化覆盖规则、实体守恒、身份与席位隔离、HTTP/SSE、未知写入结果、持久化恢复、布局、音效触发、聊天与输入法。真实手机软键盘、声音听感、系统后台限制和多成员连续使用仍需真机验收；这些不会因单元测试通过而自动视为完成。

```text
app/games/catalog.mjs       公开游戏目录：大厅、路由、人数和资源
app/games/rummikub/         拉密规则、鬼牌、布局、交互与页面
app/games/army-flip/        军棋规则、棋盘、练习与页面
app/games/flying-chess/     飞行棋规则、路径、图形、练习与朋友房间
app/games/draw-and-guess/   经典绘画规则、工具、画布、练画与朋友房间
app/games/poker414-2/       两副牌414资源、规则、电脑练习、朋友房间与角色呈现
app/games/hyakki-trading/  幽街商人卡库、规则、装备、练习与2～6人房间
app/games/parks/           PARKS全原盒规则、原创牌面、教学、练习与正式房间
app/platform/              共通回合时钟、页面会话、退出、音频与视口控制
app/rooms.mjs              房间、席位、角色和可信动作入口
server/games/              各游戏服务端适配器与明确能力契约
server/room-snapshot-compat.mjs  历史存档格式兼容
server/                    身份、持久保存、聊天、预览与战绩
scripts/                   测试、运行包构建、预检和备份恢复
infra/                     HTTPS、systemd 与托管参考
docs/design/               共通设计、游戏设计与分类模板
docs/plans/                技术计划模板与公开游戏实施计划（内部部署记录不公开）
docs/proposals/            朋友提交的游戏设计
```

规则引擎决定合法动作，房间系统决定谁可以执行，页面负责呈现与操作。服务端游戏适配器明确提供配置、超时、公私视图、存档校验与结算；新游戏不会继承拉密的摸牌、牌池或计分规则。共通页面控制器不操作任何游戏的手牌或棋盘。

## 部署与公开范围

`npm run build:release` 生成不含测试、用户数据或秘密的运行包；`npm run preflight:production` 和 `npm run start:production` 使用正式配置。生产需要 HTTPS 反代、棋牌专属客户端、稳定的服务端加密密钥、持久存储及经过验证的备份恢复。

当前正式认证实现按本项目的 Agora 契约约束提供方和身份检查端点，不是任意 OIDC 提供方即插即用的安装包。源码中的域名和 Cognito 标识是公开配置，不是登录凭据。独立部署需要设计自己的认证接入、参数和信任边界，不能复用 Agora 或日历客户端。`infra/` 是参考定义，包含收费资源，运行本机预览不需要创建它们。

本仓库暂未选择开源许可证。公开浏览源码不代表额外授予再分发许可；新增图像、音效和依赖需记录来源与使用条件。
