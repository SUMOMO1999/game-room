# 单人扫雷实施

朋友的 [设计](../design/games/minesweeper.md) 明确三档棋盘、首格保护和独立单人流程。页面使用棋牌室的米色、深青色和黄铜边框，方格与符号由样式和文字绘制，音效沿用共通合成音。首张样板在同一发布入口实现，初级布局和高级滚动共享棋盘和控制状态。

- 规则根据难度和雷图计算邻格、展开与胜负。首次开格一次采样，标记保持独立。快速开格先检查整组是否触雷。
- 页面负责输入、无障碍名称和展示。IndexedDB 将每档快照、标签页所有权和纪录放入同一事务。第二页只读，接管会使旧页后续写入失败。禁用存储时仍可玩临时局。
- 开始、结束和耗时使用设备时间。在同一页面以单调时钟交叉核对，载入时检查已经见过的最晚时间，异常局不记最快。关闭网页后的向前调时与离开时间无法区分。
- 练习大厅及生产资源清单公开单人入口。游戏没有房间路由、账号数据、正式分数或房间语音。走棋牌室共通设置、音效、返回及可安装网页入口；已打开页面可断网继续，重新加载需要网页资源可达。
- 验收三档目标格、首开、跨行、展开、误旗、快捷键、结束和恢复，覆盖矮横屏、高级滚动、标签接管和双挂载 HTTP。回退只回退静态入口，原存档仍在同一浏览器。

## 实测

- Chrome、WebKit 从练习大厅进入。三档格数、首格、旗与问号、刷新复盘、双标签接管、胜负、最快纪录、清除、再次开局和返回大厅均通过。
- 568×320 触摸视口可以滑到高级盘第 480 格并标记。转到 320×568 再转回，标记仍在，顶栏与输入模式可触达。竖屏也允许滑动游玩。
- Chrome 鼠标左右双键会在错误旗的示例中揭开真实地雷。另验证键盘导航、负数计数、触摸长按一次标记、移动取消长按。设备证据来自浏览器，实体手机触摸和音效听感待实测。
