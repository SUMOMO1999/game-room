# 你画我猜实现与发布范围

2026-10-08：经典模式已在原网址与 Agora 棋牌入口上线。当前正式版本 `8130a85ae8bdbd1c8fa5`，本页只公开产品和代码范围，内部现场资料不进入仓库。

## 当前能力

一人画、其他玩家同时猜；选词、绘画、揭晓、轮换与结算由服务端控制。大画布使用统一逻辑坐标，支持颜色、粗细、橡皮和撤销；画者只在自己的角色与阶段内持有画笔，同账号多设备也不能同时作画。其他成员看笔迹，答案只在合法阶段和角色中显示。

七个基础分类各80词，共560条种子词。有效伙伴可以维护公共分类与词条，私人词包仍按作者授权；修改保留记录，发布版本不可变，恢复旧版生成新版本。房间绑定内容版本，词库更新不会悄悄替换当前题目。自己的词包、账号资料和聊天内容不会发布到 GitHub。

共通房间已接入邀请、玩家／观众、准备、房主、聊天、暂停、退出、恢复和战绩；六主题共用设置入口。本机自由练画单独保存，不占联机席位、不判答案、不记分。

## 模块与状态

- `app/games/draw-and-guess/`：规则与内容类型、浏览器画布、工具、房间页面和练画。
- `server/games/draw-and-guess/`：适配器、可信动作、画布服务与 HTTP 装配。
- `server/content/`：词库草稿、不可变发布版本、内容索引、种子初始化和权限。
- 共通房间、会话、聊天、计时与输出栅栏保留原所有者；绘画不另建账号或房间系统。

词库和画布进入原加密持久层，业务备份扩展为13类；账号会话和身份令牌不属于业务恢复。房间格式向前兼容历史局面，旧游戏规则不会随新游戏更新。新增绘画格式后不能直接用不相容旧程序读取当前库；恢复须保留原业务库并使用相容代码。

每个动作校验成员、角色、阶段、房间与画布局面、连接代际和请求编号。笔迹提交后才成为权威状态；断连重取快照，不将结果未知的写操作随意重放。画布短授权不等于持久登录许可，私有信息继续独立检查。

## 验证范围

前批 `ffe3e59d7fbd4297c476` 的冻结包Linux2158项与独立原包2项检查通过；原入口与Agora入口各101个公开资产逐字匹配、121项匿名入口检查通过。当前UI版只改4个前端文件：设置导航样式、准备室房号及邀请、短横屏准备按钮换行，以及“恢复”文字和操作说明；原画布历史逻辑保持。24项定向检查、21项发布工具离线检查与两入口24项匿名检查通过，正式公开页面复核了设置与工具。私有接口继续要求登录；没有把历史整套测试冒充本轮重跑，合成身份和本机传输实验也不能证明真实提供方或生产共享容量。

真人手机、多人长局和高人数连接恢复继续实际验收。16参与者合成场曾出现 SSE 传输中断，未证明账号退出，也未验证所有端实际重连补齐；不把理想延迟或零断连当作已经达到的承诺。正式绘画已启用，实际账号登录续期的问题单独处理。
