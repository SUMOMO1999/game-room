# 百鬼商会 v1：完整牌资源

用于[百鬼商会朋友版](../proposals/hyakki-trading/README.md)。本页登记美术与牌面，不代表正式游戏已开放；阶段结论统一见[实施计划§11](../plans/hyakki-trading-v1.md#11-当前进度证据与下一步)。

## 全量范围

120张固定示例牌：80货物凭据、8妖怪盛典、8顺手牵羊、8护身符、6黑市拍卖、10摊位许可证。80凭据精确覆盖12配方及副本数，演示A～F固定映射和3／4／5买价、11／12／13卖价。正式牌局须独立生成并保存自己的映射和价格，不能把图鉴编号或顺序当作隐藏牌堆。

六类牌全部有[玩家短文与完整效果](../proposals/hyakki-trading/card-copy.md)。卡框、中文、数字、数量、费用、选中和不可用标识由代码呈现；内容、资源和规则分别版本化，不从插画推断效果。

## 美术清单与来源

- 六货物：黄瓜、油豆腐、灯笼、狐毛、天狗羽毛、灵石。原创SVG路径，64×64透明画布，配奶油底托确保深浅主题都可辨；无外部图形库、字体、图片或emoji。图标之外常驻名称和数量。
- 五行动：妖怪盛典的灯笼游行、顺手牵羊的伸爪狐妖、护身符的对称护盾、黑市拍卖的狸妖与拍卖槌、许可证的三格小摊。使用内置imagegen分别生成，每类一次；未使用外部API密钥、运行时AI或素材订阅。
- 一共用牌背：靛蓝月轮、朱红商结与云纹。所有暗牌完全相同，不含牌种、实体编号或玩家数据。
- 六张生成插画均保留本地源图，网页使用同内容无裁切的WebP缩放压缩版；512px宽，透明行动图512×512，牌背512×717。生成提示词见[完整提示集](hyakki-v1-prompts.json)，文件尺寸、SHA256和来源摘要见[资源manifest](../../app/assets/hyakki/v1/manifest.json)。

本批图像为本项目单独生成／绘制，没有下载《幽街商人》商用牌图、商标、扫描页或现成角色。用户已允许公开本项目整理稿；素材随仓库供检阅，不据此声称对AI画面有排他权，也不额外授予第三方商业素材许可。卡牌玩法来源仍按提案注明。

## 查看与交互

在项目目录运行 `node scripts/hyakki-preview.mjs`，本机地址：

- `/hyakki-catalog.html`：全部120张牌，可按六类／12配方筛选，逐张看完整文字，切六主题、检查缺图阅读和牌背／选中状态。
- `/hyakki-preview.html`：横屏牌桌合成样板，真实共通设置、音量、主题与聊天控件；不连接真实账号、房间或持久牌局。
- `/game/`前缀下提供相同本地入口，核对资源路径；正式生产白名单和大厅未开放本游戏。

主牌桌横屏专用，竖屏只给方向提示与退出。图鉴是资料阅读页，可竖屏滚动；完整牌局、合法动作、随机、计时、持久化和电脑练习由后续阶段实现，样板内动作不充当规则验收。

## 阅读与失败约定

- 普通牌面按可用空间分页，数量增加不缩小整副牌。名称和关键数值保持可读，点击查看16px以上完整效果；不可用牌仍能查说明。
- 深浅六主题只改变桌布及控件，货物轮廓、行动插画和奶油牌框保持一致。选中不单靠颜色，还显示文字；待回应以独立阶段提示和动作呈现。
- 图像失败隐藏破图符号，常驻名称、数量、价格与效果保留；暗牌仍显示“未公开”，绝不用某个默认正面替代。
- 声音使用项目共通合成音效；此阶段只证明本机动作与音量控制可用。正式公共事件的一次播放／恢复不补播与手势启声真机听感，按后续联机阶段另验。
