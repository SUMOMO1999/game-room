隔离小样有 13 个固定局面：起飞／不可起飞、跳后飞／飞后跳、四架同格／敌叠返库、反弹／完成／归航入口、观战／暂停、两人／三人。四个选机按钮按合法飞机派生，至少 44×44 CSS px；固定骰面仅显示，不冒充可掷骰按钮。一次确认后该骰不能再用。没有真实账号、房间、联网聊天、正式保存或战绩，退出常驻并返回自己的预览入口。

本机浏览器操作已核对 320×626、390×844、568×240、844×390、768×1024、1024×768、1280×800、1920×1080，另三次横竖循环保持选择与逻辑位置。主屏无滚动且操作目标不缩小；568×240 主板只有约112px，不宣称能读清小格，改由大列表、目的地／路线文字、全机文字棋位与 1～3 倍放大拖动视图完成阅读。低高度聊天输入／发送／关闭在模拟缩小空间内可见，自己的本机气泡可见；不是实际手机软键盘或 IME 验收。

真实 iPhone／iPad／安卓触摸、软键盘／IME、安全区、安装形态、声音听感和色觉用户仍待验；两正式入口加载、HTTP 私有路径拒绝、联网恢复及完整声音事件须在正式接入阶段验证。此句记录原Step 0小样范围；完整页面现已接平台掷骰、起飞、跳飞、归航、本人回合和结算等音效，详见下文声音定义。真实手机听感仍待最终验收。

## 最小材料与本轮清单

2～4 人、四阵营，每人四架，最多 16 架；棋盘、飞机、骰子均可用仓库原生 SVG／代码绘制。没有独特卡牌、插画、牌背、隐藏棋子、天气、装备或商业皮肤，不需要批量生成位图。

- **`fc-board-v1` 棋盘**：一张，传统四角机库与顺时针折线环道，共 52 个编号外环格、四个起飞点、各四个机库槽、各 `H1…H6` 六个归航／终点位置；每架沿 50 个环格进入自己的归航道。颜色和坐标定义见规则；形状与方向辅助必须与拓扑一致。正常显示外环／归航／起飞标记；选中与最终落点为不同描边；最近正式落点加独立标记；暂停保留棋盘但关闭行动层。逻辑比例 1:1，绘图区 600×600，环格直径 30 单位。手机棋盘 288×288 时格径约 14.4 单位，**不能把格子当独立 44px 触摸目标**，必须配大尺寸选子列表／路线摘要或放大。
- **`fc-plane-v1` 飞机**：一个共用原创路径，红／蓝／黄／绿四种阵营框与圆／方／菱／三角标记，不以颜色区分唯一身份。每架显示阵营名及 1～4 序号；总实体 8～16，图案只需四个变体。正常有轮廓；选中加双描边；可行动在列表中用文字／外框说明；不可用淡化但保留标记；最近动作另有短线标记；完成用勾与完成数，不复用“机库停放”图形。样板单位图标 30×30，实际可选列表目标至少 44×44 CSS px；一格本方最多四架，以数量徽标加四个序号选择项表达，不把叠图当四个触摸点。
- **`fc-die-v1` 骰子**：共用方框与六种准确点阵，数字 1～6 为文字备用。正常结果固定；等待服务器时显示“掷骰中”，不能提前随机展示可被误认作已确认的结果；待选择明确显示当前保存骰面；不可操作／暂停说明原因。行动目标至少 48×48 CSS px，样板上方 44×44 仅为不可操作骰面目录，低横屏示意骰面 48×48。结果动画、轻动效与无动画状态均必须显示同一个已保存值。
- **`fc-route-v1` 路线与状态标记**：普通行走为连续路径，跳跃为带 `+4` 标签的短虚线，捷径为飞机／端点标记和连接线；起飞不渲染六步路线。四条捷径都标出跨过对面 `H3` 的位置，默认安全还是跨线攻击按已确认规则决定，不能从图片猜。选中、合法目标、最近落点和完成标记有不同描边／线型；色觉体验仍待真实用户验证。样板给出四条传统捷径与红色跳后飞路线，正式操作场景仍须逐一核对。
- **`fc-controls-v1` 操作呈现**：骰面、轮到谁、待选说明、飞机序号列表、确认／取消、放大和退出入口。四阵营图标与牌局图一致；多机同格列表至少四项。样板给 320px 竖屏和 568×240 低横屏信息排布示意；不是可点按钮或响应式页面。
- **声音**：完整页面复用平台合成短音与启声／静音控制，新增掷骰、起飞、跳飞和归航音色，另有移动、撞机、本人回合、聊天、错误、开始、暂停／恢复及结算。按正式投影去重，POST／SSE同次结果只一次，恢复不补播；规则中可逐类试听。没有音频下载或外部许可依赖，真实手机触摸与听感仍待验收，静音仍有文字／描边反馈。
