# 两副牌 414 原创牌面资源

2026-10-09，资源版本 `p414-2-art-vector-v1`，实体定义版本 `p414-2-cards-v1`。对应[两副牌设计](../design/games/poker414-2.md)及[唯一实施计划](../plans/poker414-2-v1.md)。本文记录原创资源及验证方法；当前发布和本机／真机验收范围以唯一实施计划§11为准，不在资源文档重复维护进度。

## 内容与来源

- 52 种普通牌面：黑桃／红桃／梅花／方块各 13 种，角标为 3～10、J、Q、K、A、2；同一字号体系由游戏页面样式控制。花色使用本仓库原创 SVG 路径，不加载符号字体或第三方图标。
- 2 种王：小王使用蓝色双角铃帽和菱形，大王使用红色五角冠和日轮。轮廓、文字、颜色三种区别同时存在，不使用笑脸或 emoji。
- 每种牌面两份实体，共 108 张。两份共用图形，但实体 ID、选择状态和可访问名称不同。实体定义不包含任何身份、隐藏手牌或对局信息；牌面公开不等于可以读别人的手牌。
- 统一牌背一款：藏蓝底、金色双菱形与细线网格；无实体、花色或副本编号，不因隐藏内容改变外观。
- 阅读标识九款：三档火箭各一款，以真实不同花色／非红桃同花色／纯红桃的两张4加一张A示意并附完整中文名称；三至八张炸弹各一款，叠牌轮廓和下方计数点与张数文字一致。标识只帮助阅读，不代替真实牌型判断。
- 图形、文字排布合同为本项目原创代码，可随仓库分发；未使用外部图片、字体文件、品牌素材、付费生成或远程资源，没有新增许可或服务依赖。

## 模块与尺寸合同

[cards.mjs](../../app/games/poker414-2/cards.mjs) 提供 `SUITS`、`CARD_VERSION`、`makeDeck()`、`getCard(id)`、`cardLabel(card)`、`rankLabel(rank)`。数字 rank 3～15 对应 3～K、A、2，16／17 为大小王，王的 suit 为 `joker`。`faceId` 为 `p414-2-<suit>-<rank>`，实体 ID 再加 `-<copyId>`；copyId 为 0／1。每次 makeDeck 返回独立实体，getCard 返回不可变标准定义，未知 ID 或与 ID 不一致的牌对象明确拒绝。

[art.mjs](../../app/games/poker414-2/art.mjs) 提供 `ART_VERSION`、`renderCard(card, {selected, disabled, interactive, compact})`。每个实体只生成一个 button（可操作）或 span（只读），不内嵌事件；页面拥有操作、尺寸、选中上提和状态样式。button 有原生 disabled、aria-pressed、完整花色点数及副本序号；只读牌不进入键盘操作序列。

另提供 `renderCardBack()` 生成统一只读牌背；`renderPatternBadge({kind: 'rocket', level: 1|2|3})` 或 `renderPatternBadge({kind: 'bomb', count: 3|4|5|6|7|8})` 生成只读说明。未知牌型、越界参数或额外字段拒绝；不输入实际手牌或权限。牌背不输出 `data-card-id`，标识也不能被当作可选实体。

- 花色 SVG 逻辑坐标 32×36；王的逻辑坐标 64×78。矢量可等比缩放，不需要分别制作 108 张位图。
- 牌背逻辑坐标72×96，使用 `p414-card__back-art`；火箭／炸弹逻辑坐标102×52，使用 `p414-pattern-badge__art` 和正常 HTML 的 `p414-pattern-badge__label`。资源检查面板按可用空间等比显示，文字不依赖图片。
- DOM 子项为 `p414-card__corner`（点数及角花色）、`p414-card__center`（主图形）、`p414-card__caption`（普通中文文字）。点数与花色／王的名称使用正常 HTML，SVG 不显示时仍保留牌的含义。
- 公共 class 均限 `p414-card` 范围；红黑、大小王、选中、禁用及紧凑状态有明确 class。资产本身不把布局或触摸目标强写为固定像素，真实手牌区仍须保证至少 44×44 CSS px 的可操作范围或提供等效放大选牌。
- 游戏页面与本机练习复用同一资源；公开 art/cards 及必要依赖按精确白名单登记。练习需要的纯规则须独立审查导入闭包，不能因资源已公开而顺带暴露服务端适配器、存储、测试或夹具。
