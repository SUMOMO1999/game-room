# 幽街商人数字版 v2 资源与牌面

新版按[51种实体卡目](../proposals/hyakki-trading/physical-card-catalog.md)和[数字裁定](../proposals/hyakki-trading/digital-rulings.md)制作，替代旧120张示例牌作为后续实施输入。[旧资源记录](hyakki-v1.md)仅保留历史；实施进度与验收结论统一见[计划§11](../plans/hyakki-trading-v1.md#11-当前进度证据与下一步)。

## 内容与美术归属

运行内容由 `app/games/hyakki-trading/content/definitions.mjs` 维护：货物19种40张、摊位许可1种5张、普通人物13种29张、监视人物8种14张、道具10种22张，共51种110张。实体副本与定义分开；图鉴数量不是已经洗好的正式牌堆。火器、番货、奇物、异兽、文玩、盐铁数字初值各6件，是用户授权维护者选择的数字规则，不标成实物核实。

39项主体位于 `app/assets/hyakki/v2/`：

- 六货物图标与统一牌背：自制SVG，保持轮廓与标签，不用emoji代替资源。
- 21人物、10道具、一摊位许可：内置imagegen分别生成的原创插画，统一墨线、米白纸底及朱红／青绿／金色点缀。每种有独立图案；网页用WebP，没有运行时生成、AI识牌或素材订阅依赖。
- 51卡面由DOM组合配方、买卖价、类别、监视徽记、费用／时机、短文与完整效果。中文字和规则不画入插图，调整规则不必重做插画。

`content/manifest.mjs` 维护39主体、51卡面、定义与实际阅读场景的映射；`app/assets/hyakki/v2/manifest.json`记录文件尺寸、摘要和来源类型。生成提示词与原图路径保存在本地验收目录，不把个人路径、朋友聊天或商业扫描图放进公开资源。

本批不复用实体商业牌面的美术、商标或扫描图片。玩法与牌效参考来源仍由提案记录；自制插画不意味着取得原商业美术的许可，也不声称AI图像有排他权。

## 页面与阅读规则

开发入口由 `scripts/hyakki-preview.mjs` 提供，支持根路径和 `/game/`前缀。图鉴 `/hyakki-catalog.html` 列出全部51种，能按五类、名字或来源编号查询，显示每种副本数，打开完整效果；图鉴可竖屏阅读。

`/hyakki-preview.html` 是20种合成场景的页面样板：准备室、本人／对手／观战、私看留弃、两种回应、候选选择、两种拍卖、三类重分、工具、满摊、暂停、掉线挂起、结果和密集手牌。中央行动条、左侧牌堆／弃牌、右侧公共货摊，本人商铺、工具和手牌独立分区。这里只演示选择和页面切换，未实现经济结算、真实房间或续存，不属于独立练习室。

- 普通手牌空间足够时展示整张牌；短横屏采用可读摘要和详情，不将长配方挤入缩小卡面。分页不压缩整副手牌。
- 完整效果正文至少16px；普通卡关键文字至少14px。牌名、图形与文字共同区分类别，不只靠颜色。
- 暗牌只展示统一背面；图片缺失仍保留名称、数量、价格和效果，不以另一牌面冒充。
- 人物与道具插画完整呈现，纸色与卡底柔和衔接，不另套明显的矩形底框；加载中也保留牌名占位，完成后才隐藏，失败仍可识别卡牌。中央行动条用离散刻度与灯笼游标表达已用步数，属于状态轨道，不画成一排可点击按钮；随1～10行动和横屏高度适配。
- 道具已用状态有文字和纹理；同名工具按实体选择，不能以牌名混用状态。
- 本机选择与报价草稿在收起、查看详情、旋转后保留；换角色或销毁页面清除私牌DOM。
- 真实共通聊天、设置、音量和六主题在样板内装配。竖屏提示转横屏，设置、退出及当前待决入口仍可达。

浏览器模拟检查与真实手机触摸／听感分开记录；本地页面通过不代表规则、联机、恢复或生产验收通过。
