# 百鬼商会设计入口

《百鬼商会》参考实体桌游《幽街商人》。**当前玩法以[新版规则记录](current-rules.md)为准**：双人、取牌与用牌两阶段共用行动标记，默认上限5且可在开局前调整；每次只看1张，弃掉才可继续看，一旦留下就进入用牌；看牌无论留弃都计1步，普通用牌计1步，免费例外，每次换人归零。回合末达到60两才触发末回合／最终财富结算，不能照搬旧稿“动作完成即胜”。

用户已确认五类牌：货物、摊位许可、普通人物、带监视标记人物、道具。完整逐牌效果及副本仍待补；旧120张仅是朋友稿的示例牌，不代表新版完整卡库。当前只有本地资源、分类／布局样板，**尚未开放正式可玩游戏**。阶段进度唯一维护在[技术计划§11](../../plans/hyakki-trading-v1.md#11-当前进度证据与下一步)。

## 2. 本轮范围与材料

**原稿A1、A2、A6：**

- 人数2～6，独立竞争，无队伍、阵营、共同财富、中途破产淘汰。
- 每人初始20两、4张随机手牌、6格摊位、0货物。
- 公共货物为黄瓜、油豆腐、灯笼、狐毛、天狗羽毛、灵石，各20个，共120个。每个实际货物占1格。
- 所有六类牌放进同一公共牌堆，使用后的牌进入同一弃牌区。维护者D01定为120张：货物80、盛典8、偷窃8、护符8、拍卖6、许可证10。
- 货物牌载有3～6个货物，允许同种重复；基础买价3／4／5两，卖价11／12／13两，均由系统随机生成。D01采用12个可重复配方及每局随机货物映射，价格独立等概率生成、整局固定；不再逐张完全独立随机组合。
- 五种行动牌为妖怪盛典、顺手牵羊、护身符、黑市拍卖、摊位许可证；数值及行为见卡牌目录。
- 手牌数量、扩建后的摊位容量没有规则上限。技术上的存档配额不能变成暗中的玩法上限。
- 公共银两采用无限银行，接收付款并发放收入（D04）。游戏银两只属于本局，不自动等同棋牌室永久娱乐积分。

货物牌是买卖凭据，实际货物是摊位中的库存。买入会消耗货物牌，之后卖出还需要手里另一张符合现有货物组合的牌，不能把已弃掉的买入牌立即再卖一次。

原稿明确不做：角色、阵营、地图移动、RPG成长、等级、技能树、复杂任务、玩家直接交易及大量特殊牌。一局目标时长、可分几次完成和长期内容维护方式尚未给出。

## 3. 区域与公开范围

- **本人手牌**：本人查看完整内容。其他玩家和观众不能获得隐藏手牌或暗牌编号。手牌张数公开（D08）。
- **每人摊位**：实际货物和个人银两公开；容量与当前行动力应在主屏清楚显示，这是维护者的呈现要求。
- **公共货物堆**：六类剩余数量公开。买入从这里移出，卖出移回。
- **公共牌堆／弃牌区**：D08公开牌堆张数、弃牌全部正面与历史；隐藏牌序不可见。
- **拍卖区**：承接从公共牌堆取出的三张牌；三张一次抽出，只揭示当前拍品；保留公开成交历史，未来拍品隐藏（D03、D08）。拍卖中的牌不能同时留在牌堆、弃牌区或手牌。
- **待结算区**：维护者建议显式表达已确认但仍等待防御或竞价的动作；不要靠客户端弹窗保存。这是状态建模建议，不增加一种可随意使用的牌区。

普通排序、放大和选中只影响本人的显示，不改变库存、牌序或拍卖结果。公开成交已经让人看见的牌不能承诺“自动忘记”；同时不能借公开历史直接泄露后来洗入牌堆的实体位置。

## 4. 从开局到结束

### 4.1 准备和开局

按平台等待室完成选玩家／观战、房号邀请、准备和房主开局。原稿规定开局后不能加入新的参赛者；平台允许后来成员观战，原参赛账号重连仍恢复原席位。

先建立本局材料，随机决定先手，每人发20两、4张牌并设6格空摊位。首手之后固定轮序，原稿写“暂定顺时针”；D09确定每局随机先手，此后沿准备室座位固定轮序，离席只跳过不重排。2～6人初始共发8～24张牌，整副固定120张。

### 4.2 个人回合

`开始回合并获得5行动力 → 至少摸1张牌 → 用剩余行动力执行动作 → 结清当前动作 → 回合结束与奖励 → 下一人`

行动力只在本回合有效，不累积。普通摸牌、买货、卖货各花1点；行动牌按各自定义。已确认并完成的动作不可撤销，包括随机摸牌、重摸、买卖、用牌、出价及成交。

玩家可以主动结束回合；5点用尽则自动结束。两堆都空时本回合免必摸；全轮无人能抽牌或执行合法主动动作才按D02停摆结算。最后1点发动偷窃或拍卖，须先结清整个效果再结束，不能显示0点就提前换人（D09）。

### 4.3 基础动作

**摸牌／重摸（原稿A3-1、A6-10）**：花1行动力从顶部取1张加入手牌。不想要刚抽的牌时可弃掉再花1点重摸，可以连续；行动力不足时保留最后一张。D02只允许紧接刚摸的牌重摸，夹入其他确认动作就关闭该次机会；被换的牌不参与本次重洗，无替牌完整拒绝。

**买货（原稿A3-2、A6-3）**：选本人1张货物牌，检查行动力、金额、完整库存和空位。成功时花1行动力及本次买价，将所列实际货物从公库移到摊位，货物牌入弃牌区。原稿明确缺钱或缺货不扣钱、不扣行动力、不弃牌；容量不足同样不得部分买入，失败保持状态是平台动作要求。

**卖货（原稿A3-3）**：本人必须拥有货物牌所列全部实际货物。成功时花1行动力，货物回公库、收取本次卖价、货物牌入弃牌区；不满足组合时没有收入、不扣行动力、不弃牌。卖价修正见妖怪盛典；银行无限供应（D04）。

**主动／反应牌（原稿A3-4～6、B）**：主动牌只在本人回合使用；护身符只在本人被偷时响应。非当前玩家可看牌及公开区域、参与拍卖或合法防御，不能主动摸牌买卖。各牌费用、选择、效果、去向见[目录](cards.md)。

### 4.4 回合奖励与终局

正常结束且实际摸过牌、累计用3行动力或更少，回合结束获1两；用4～5点、未实际摸牌或超时结束不获奖励，每回合最多一次（D05）。剩余行动力清零；妖怪盛典在本人当前回合结束时失效。

原稿A4、A6规定：任意玩家到60两后，完成当前正在执行的行动，立即结束，其他人不再行动；同一效果使多人同时到线则并列。无提和。59两卖货得12到71是已给例子；D09确定59两因正常回合奖励到60立即胜，先结算再换人。当前内容没有已定义的同时给多人增加银两效果，并列规则只在确有这种合法效果时适用。

“当场到线即胜”是朋友版的明确意图，不自动套用实体版的回合补齐。最终财富、操作记录和胜者可用于本局结算；永久娱乐积分的换算未定义，不能把银两直接记进现有414积分账户。

### 4.5 计时、暂停、退出和恢复

D05把普通180秒定为整个主动回合，不因动作重置；防御10秒、逐次竞价15秒另计并冻结主动时间。主动超时只补欠缺的必摸后结束且无奖励；防御／竞价超时放弃相应选择。

暂停沿用平台全员同意／任一在席玩家恢复的机制，所有当前有效阶段时钟均冻结剩余值，恢复继续；离线保席时限不被暂停延长。已有确认不能因设置弹窗或刷新退费、重抽或延长期限。正式局打开设置／聊天不是暂停申请。

返回大厅、退出棋牌登录、断线、认输和明确退出房间是不同动作。D06规定断线保席30分钟；主动认输或到期离席，当前完整效果结清后返货、弃手牌、钱归银行并移出轮序，其他人继续。剩一人胜，全员退出取消；已确认报价及发起者兜底不撤回。账号与其他游戏保持。

## 5. 具体局面与检查清单

这些是规格例子／纸上推演，不是运行测试结果。行动力同时列原稿前提，避免用不合法的回合顺序解释新规则。

- **E01 买入**：甲20两、已摸牌后4点、空摊位；花4两买入黄瓜2、灯笼1、狐毛2。结果16两、3点、5货物，所用货物牌弃掉；对应公库减少2／1／2。来源原稿A5-1。
- **E02 非法买入**：甲2两试买4两的牌，原稿规定全不变；甲已有4货物试买3个也不得超过6格。后一项补作容量与失败原子性检查。
- **E03 卖出并胜利**：甲59两、已完成必摸且有行动力，持有完整对应货物与卖12两的牌。成功后货物归库、牌弃、银两71，动作完成即结束。来源原稿A5-6。
- **E04 反应**：甲付1点偷乙灵石，乙在10秒内出护身符。货物不动，两张牌弃，甲行动力不退；第三人不能代防。来源原稿A5-3及A6-6。
- **E05 重摸与奖励**：甲5点先抽、弃后重抽，共花2点，保留第二张后结束，获1两、余下3点不带入下回合。来源原稿A5-4；重摸与空堆按D02完整拒绝或豁免。
- **E06 价格**：盛典选黄瓜，某货物牌含黄瓜2、基础买3卖11；本回合买1卖13，按整张牌修正一次，不因两个黄瓜再翻倍。其他人不享受此效果。
- **E07 拍卖**：原稿示例为甲1、乙2、丙3、甲退、乙4、丙5、乙退；丙付5给公共银两，牌归丙。D03补齐从发起者起固定轮询、跳过最高者与已退出者；每件重置资格，D04预留兜底资金。
- **E08 临界奖励**：甲59两，完成必摸并总耗3点以内后结束。奖励到60应纳入终局检查，不能先切给下一人导致抢先操作；按D09已确定该顺序。
- **E09 恢复／并发要求**：拍卖第二件时刷新，仍是原三张、原报价、原已退者和原期限；偷窃超时与护身符同时提交，只发生一个结算。这是维护者验收要求，尚未实现。
- **E10 密集与隐私要求**：6人、多次扩容、大手牌、观战者；转屏及聊天键盘期间仍能看见当前拍品、防御对象、倒计时与退出；私人牌不经日志或旁观流外泄。

尚缺一个**从真实初始牌堆到终局的完整可复现演示**。按D01～D09的基线在技术计划前完成；当前局部例子不代表完整闭环验证。经济与僵局风险的有界推演见问题单末尾。

## 6. 棋牌室接入要求与维护者建议

这是设计范围，不是本轮技术实施合同；具体模块、接口和测试将在后续[技术计划](../../plans/game-implementation-plan-template.md)中核对。

### 6.1 默认交付内容

- 准备室有房号、复制邀请、2～6位成员、观众、准备／开始、明确退出和设置；在受支持的窄屏上实际可读可点，不能藏掉房号。
- 正式房间复用现有身份、稳定席位、聊天、未读／本人气泡、主题、音量、规则、邀请回房和战绩；本游戏另定义可行动者、反应、拍卖与离席后果。
- 主屏持续显示自己的回合、真实轮序、钱、行动力、摊位占用／容量及六类库存。手牌提供分类、手动整理、可用／不可用原因和点开大卡；不能只靠微小卡面长文操作。
- 防御和竞价是临时主任务，有不同于普通回合的高亮、提醒和可见出口；聊天气泡、键盘与设置不能遮住10／15秒操作。静音也能读懂谁在等自己。
- 一屏可完成主要操作；大手牌、详细弃牌与长规则用分页／查看层，主牌局不依赖纵向滚动。拍卖主区和货物区按手机竖横可用空间重排，不缩成一团小字。
- 返回大厅保留席位；认输或离房弹窗说明确定的后果。浏览器返回、刷新、断流、页面被杀不等于主动认输；恢复不整页闪白、不重新随机。

### 6.2 独立练习必需

按平台默认包含单人练习。**建议一人＋1～5位电脑，另附可完成的买卖／防偷／拍卖教学**；具体电脑策略、提示和练习计时差异在计划前定清，不以只读图鉴或卡面样板代替练习。

复用正式规则和卡面；电脑只用本角色可见信息。本机保存练习进度，后台／弹窗暂停、刷新继续、冲突或坏档明确提示，可重开、退出；不承诺跨设备同步，不产生正式银两、积分或战绩。本机练习无房间成员，不伪造聊天、房号或邀请。

### 6.3 状态和内容边界

- 权威规则保存钱、行动力、库存、每份卡当前已生成的参数及区域、顺序、阶段和结果；卡类别`typeId`与本局实体`copyId`分开。
- D01规定货物组合和价格开局固定；重连不能刷新参数。客户端不持有未揭示牌堆或他人手牌，隐藏实体重洗不能被公开编号追踪。
- 偷窃和拍卖要保存已付费用、选择目标、抽出的牌、待回应者、报价／放弃、剩余期限和已完成子步骤；提交成功但回执丢失时读回，不重新扣费或抽牌。
- 每种货物公库与所有在局区域总计20；银行无限供应；玩家银两变化与银行收支记账对齐，不要求有限银行库存守恒。退场材料、临时拍品和待处理牌也必须有明确去向。
- 本人手牌排列与未提交选择属于显示／草稿；悬浮、拖动预览不产生正式交易。确定买卖后才广播公开结果。
- 每局固定规则、卡定义和资源版本。实体参数不因再抽、洗回或内容热更新而改变。改新卡或换数值不改变旧局；未知定义与不兼容存档明确拒绝，不能自动归为普通货物牌。
- 不预造通用卡脚本引擎。首版六种行为分别实现并核对关键交互；未来新增机制仍要设计、实现和测试。
