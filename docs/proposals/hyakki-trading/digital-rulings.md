# 幽街商人数字版规则裁定 v1

2026-10-10。沿用户“待确定由我们定”的授权，补齐实体说明书没有写细的交互。**此页是朋友数字版的维护者决定，不冒充官方裁判解释，也不表示已经实现。** 实体事实、原牌效果及51种110张配比分别见[当前规则](current-rules.md)和[实体卡目](physical-card-catalog.md)。旧D01～D09不参与本版判定。

## 1. 配置与适用范围

- `ruleVersion=yousei-digital-v1`，双人，完整51种110张入局；不删复杂人物或道具来凑首发。正式朋友局与本人＋1电脑的练习使用同一规则和卡目。
- 行动上限`actionLimit`开局前可设整数1～10，默认5；全员准备后随局固定。省步奖励为**主动结束时至少余2步得1两**，每回合一次；上限1时无此奖励。换人不带入剩余行动。
- 每人初始20两、5张手牌、5普通货位＋1收费临时位、0货物、0道具。先手由服务端公平随机一次，整局固定；再来一局重新随机，不按昵称或当前房主推定。
- 银两用非负整数账本，银行不受实体硬币面额／张数限制；玩家不能借贷或透支。买价最低0，卖价不设人为封顶。整数溢出拒绝写入，不按溢出结果继续。
- **数字版新局默认火器、番货、奇物、异兽、文玩、盐铁各8件，共48件**，全部初始放公共区。2026-10-10用户要求开局前可调，`goodsPerType`为4～20的整数，六类使用同一数量；与行动上限一起在开局时冻结，正式局和练习使用相同边界。改变默认值不改变110张牌的定义／配比、商铺容量或临时位收费，也不代表已经验证平衡。
- **旧房间／旧局缺少`goodsPerType`时按各6件／共36件读取**，原公共区、个人库存和待分配材料保持，不重分配、不补到8件，也不套用最新默认值。显式的新局配置与冻结初始向量须一致；非法类型或范围拒绝，不能静默改成默认值。
- 实体“6种×36”的逐类分配仍未核实；历史物理卡目中的各6件记录是首版数字决定，不随新配置重写成实体事实。许可正面可后补，5张、费用和效果已有说明书依据。两项只作非阻断来源补全。
- 全套副本、初始货物向量、规则／内容／美术版本随局冻结。后续资料修正只改变新局；历史局继续原版或明确迁移，不能读取最新目录偷偷换牌。

## 2. 回合与计步

回合开始 → 抽牌前窗口 → 逐张取牌（首次必做）→ 用牌 → 完成当前效果 → 回合末 → 对手。

- 按2026-10-10用户修正，每回合必须先完成一次普通`peek`，不能直接转用牌或主动结束领银两；留与弃都算，不能用道具动作代替。牌堆与可洗弃牌均空时允许进入用牌／结束；系统超时仍可正常收尾，不奖励银两。旧存档已经进入用牌的回合不倒退、不补扣；下一回合应用必摸要求。
- `peek`只取顶部1张到自己的私有待留弃区，立即计1步。留或弃不再计步；未决定前禁止再看、用牌或直接切人。
- 弃后可继续看，也可结束取牌转用牌；留下一张则必须转用牌。一旦转用牌，本回合不再普通看牌。牌效抽牌不触发普通逐张留弃流程。
- 纸上仙可在本回合第一次普通看牌前、且尚未关闭取牌阶段时使用；每张计1步且横置。交换后仍须完成首次普通看牌；必须为看牌保留1行动，只有1行动时不能先用纸上仙。同名多张按实体逐一使用；第一次普通看牌后窗口关闭，当回合在用牌阶段刚装的纸上仙不能立即激活。
- 普通用牌／安装／激活在开始动作时占用1步。动作引出的抽选、付费选择、反制、竞价和分配不会重复扣主动行动；原文明确免费者按例外处理。
- 达上限时只结清已开始的留弃／牌效和合法回应，随后自动结束，不能新发动免费动作。0步不能成为取消已提交效果的方法。
- 正常主动结束给省步奖励；用满、主动超时、认输、离席收尾不奖励。先结效果、奖励、道具复位及临时状态清理，再按回合末银两检查60与最后一回合；最后一回合只能执行一次。
- 首次普通摸看后可以主动结束，并按剩余行动判断省步奖励；首次未摸时不得以主动结束绕过。旧行动上限1的局会在摸看并完成留弃后自动换人，不能额外用牌。

## 3. 动作原子性与回应

- 确认前可以改选／取消；服务端受理后，牌移入待结算区、行动和明确的发动费用一次入账。失败校验保持所有状态；已经看牌、公开或完成交易不可撤销。多步骤效果保存当前步骤、选择者和已支付内容。
- 待结算牌不属于手牌、弃牌或可抽牌；县丞、典史、堪舆师等计算手牌时不包含当前发动牌。效果、回应都结束后才归弃牌或指定新主人。
- **锦衣卫**：监视人物公开牌名及已选公开目标后，对手先决定是否使用锦衣卫；在此之前不抽秘密牌、不公开双方手牌、不移走目标材料。取消后，人物占用的1步不退、人物与锦衣卫均弃置；未执行的效果费用不扣。锦衣卫自身免费且不触发另一张锦衣卫。
- **番商**：合法货物交易全部完成后、货物牌尚未入弃牌前，给对手一次回应机会；出番商则该货物牌归其手牌，番商弃置。原买卖照常成立，不能被倒回。普通人物和道具不能被番商拦截。
- 买办中的三件货物牌是一次真实的卖货子动作，免额外计步，也开放番商；书算对该子交易卖价生效。外层买办与子货物牌分别处置。锦衣卫不能取消买办。
- 弃牌顺序固定：被反制人物先弃、锦衣卫后弃；正常嵌套先完成子效果材料的去向，外层人物最后弃。公开翻出/流拍的多张牌按原抽取顺序依次入弃牌，最后一张在顶；玩家选择的批量弃牌按固定内容ID＋实体序入堆；双方同时弃置按使用者先、对手后。这个顺序随事件保存，纸上仙取顶牌才有唯一结果。
- 一个响应窗口最多处理一次；不按对手是否持有回应牌改变公开窗口或自动跳过，以免泄露手牌。对手可主动放弃。服务器在同一事务内裁定回应与截止到期，只有一个结果。
- 无待结算效果时不允许空打番商或锦衣卫。其他玩家不能借响应提交普通主动牌；聊天、规则阅读与本人手牌整理不改变当前决策。

## 4. 货物、位置、价格与许可

### 库存与临时格

- 以货物实体及占位为权威数据，画面拖动只是阅读安排。普通容量为 `5+3×已买摊位数`；自动先占普通位，额外最多用1临时位。
- 每个完整的收货／交换效果结束时，若临时位由空变为占用，额外付2两；已占用且完整交换后仍占用不重复收费。分成两次独立动作先腾空后再次占用，要再次付2两。动作确认时展示这笔费用。
- 出货或扩容使库存降到普通容量以内，自动腾空临时位，不退此前2两。不能通过自由拖格触发退款、重复收费或免费加容量。
- 普通货物牌必须有完整买价、临时位费、公共整组库存和容量才可买；卖也须有整组货物。普通交易不足不部分成交，全部保持原状。
- 人物得货的容量例外：允许从“自己原库存＋本次所得”中挑保留，舍弃物回公库，不得丢对手未转出的货物。临时费付不起就只保留普通容量。自愿放弃部分收益不退发动费用。
- 道具产生单件货物时，发动前必须具备足额成本、货源及至少1个可负担的位置，不套用人物任意舍弃库存的例外。许愿井是等量交换，按完整交换后占位收费，不要求先临时多一个空位。
- 两人重分货物时，原库存先进入公开待分配区，按使用者先、轮流每次1件领取；满位且不能付临时费者跳过，已付临时位费的占用不能凭重分重复征收。双方均无法再放的余货回公库，不允许反复领了丢、丢了再领。
- 固定数量的自主采购／交换要求公库足额：匠人2同种、货郎等量异种、牙郎2件等。没有合法种类／对象就不能发动。被动或多方效果中的货源不足按该分支可得数量处理，不从空气生成货物；C01双方收益详见逐卡补充。

### 价格和扩摊

- 每张书算叠加一层，仅使用者当前回合有效：买价 `max(0,印价-2×层数)`，卖价 `印价+2×层数`。临时格、许可、道具、竞拍、人物固定费用不受修正；回合末清零。
- 许可从5块公共扩展板中取1块，每块3格；整局第一次取板6两，之后3两，另耗1行动。无板或钱不足不能打。扩展板归属与全局已购数持久保存；货物或道具重分不转移扩展板。

## 5. 牌堆、搜索和分配

- 普通抽牌按堆顶顺序；堆空才洗当时合格弃牌，不把手牌、待结算牌、正在挑选的牌或拍品洗入。随机牌序在写入前固定，重试和重连沿用。
- “抽N张”在双方所有可洗牌都不足时尽量抽取剩余张数；无牌不创造占位牌。卦师至少1张可发动、最多看6张；典史补至5也只能补可得数量。
- 具有不可拆分配义务的两仪灯至少需2张、花魁至少需3张可抽才可发动；匠人、货郎和普通买卖亦须足额。以当前公开牌区计数校验，不读取秘密牌种来决定按钮是否可用。
- 鹤骨笛先弃1／2张，再抽同数；支付的弃牌当步可参与后续洗牌，因此可能抽回刚弃的牌。这不改变已使用的行动或道具朝向。
- 卦师私看顶6张，选1入手，其他按原相对顺序背面放回堆顶；不允许重排，旧序号在秘密牌堆中不公开。两仪灯2张只有使用者先看，分完各自只收到自己那张。
- 貔貅袋公开依次翻到首张货物牌；本次已翻非目标暂存并公开，搜索中不再洗回，结束后入弃牌。每个候选实体本次最多翻一次；没有货物牌则结束搜索，已花的1步／横置保留，免去取得目标的后付1两／弃手牌费用。
- 貔貅袋发动前只要求至少1张可搜索牌，且自己能付1两或弃1张手牌；不通过隐藏牌种预判成败。找到后必须支付可行费用，不能看完反悔；目标牌尚未入手，不能用它本身付弃手牌费。
- 堪舆师由服务端从对手当前手牌均匀盲抽，抽中实体与结果固定后再选交回；不向对手或观众泄露被看正面。自己可交回刚抽牌，不能先交后抽。
- 无牌可抽的普通取牌可直接跳过；无合法目标的纯主动牌不能空放消耗。复合效果至少有一个分支可执行收益才可发动；存在合法交换/重分对象时，不要求最终净收益为正，允许堪舆师原牌交回或许愿井换同种货物。已进入的被动分支尽量完成，不要求对手支付不存在的资源，不回滚已经公开的信息。

## 6. 拍卖与道具联动

### 一组拍品一次成交

牙郎拍2件货物，花魁拍公开3张牌。均由使用者先报，起价至少1两，交替加价至少1两；每次只允许不超过当前银两的整数报价。最高价预留、双方不能插入其他花钱动作；成交款归银行。使用者也可第一次直接放弃，此时对手可报至少1两或也放弃；两人都未报价则货物回公库／牌入弃牌，发动行动和人物不退。已有报价后另一人放弃，立即按最高价成交。

货物报价必须存在至少一种不透支的保留方案；允许舍弃旧货而只用普通格的玩家，不强制额外预留2两。标金支付后的余钱决定能否再付临时位费；人物容量取舍允许得标后选择保留货物，但不能以弃拍品为由撤标退钱。拍品固定和公开后，刷新不重抽、返回详情不重开拍卖；价格、已退出者和期限随局保存。

### 留场、重置和借用

- 同名道具各自有实体ID和横置状态。普通激活必须竖直；更换道具时可弃自己任意旧道具，横置的也可弃，安装仍花1步。
- 光棍重分后按牌文明示竖直摆放，当前玩家可花剩余行动再次激活拿到的道具；纸上仙仍受抽牌前窗口限制。重分不是重新安装，不收额外安装行动。
- 术士先弃对手选中的道具，无论它是否横置；之后可选择借用效果，最多一次，不安装、不多计行动。效果费用与条件仍由使用者承担。纸上仙可被弃，但不得借用其效果。
- 借九转金炉／贪嘴泥翁时，被弃的对方道具已不在使用者道具区，不能再次当成本；只能弃使用者自己的1张手牌或自己场上的1张道具。外层待结算术士也不能当作手牌弃。无可行支付时只执行拆道具，放弃借用。
- 自己正常激活九转金炉／贪嘴泥翁，可弃本道具、自己1张手牌、自己任意1张已安装道具（三选一，横置的也可）。付其他牌时本道具继续横置留场；自弃就不参与回合末复位。

## 7. 逐卡补充与验收入口

[逐卡数字合同](card-resolution-contracts.md)逐一给出31种人物／道具和货物／许可通则的使用条件、选择、顺序、去向、可见性和失败例子。它补充实体卡目，不改原牌功能。全部51种定义必须能映射到合同及至少一个验收场景，不以“类似其他牌”漏掉特殊行为。

## 8. 倒计时、离席与恢复

- 正式局主动回合默认30分钟；自己看牌、选支付和选牌继续消耗本回合时间。轮到对手作决定时冻结主动剩余值，该选择用60秒；返回自己后恢复原剩余值，不重给30分钟。
- 反制／番商超时视为放弃，竞拍超时视为放弃。其他必须完成的选择超时按固定合法顺序选择最小可完成项，不重新随机；手牌／临时秘密区的自动选项只对有权者可见。
- 主动回合超时：待看牌默认留下；已提交牌效按预设合法默认结清，然后结束回合，不摸额外牌、不获省步奖励。恢复期间不得重抽或再付费；超时与人工提交只完成一次。
- 固定默认规则：先完成原已提交支付；新增二选一优先牌文第一项中合法者；枚举选择按内容ID＋本局实体序稳定选，保留货物优先原库存再本次所得；抽取顺序只按已保存顺序。不可用、已离开区域的候选重新在同一决策的当前合法集合中选，不把决策重开。若集合意外全空则按该效果不足规则结束并记录原因。
- 正式局全员同意手动暂停，最长保留7天；当前阶段剩余时间冻结。双方回到有效席位后，任一在席玩家可继续。手动暂停后的离线不套用意外断线30分钟取消；共同暂停截止不因刷新延长。设置、聊天、切后台和横竖屏不是暂停请求，不能承诺浏览器在后台永不挂起。
- 对局进行中，任一参赛席位确认离线就自动挂起经济动作与游戏时钟，保留身份、席位和原步骤30分钟；同账号其他设备仍在线则不算离线，仅观众在线不算参赛者在线。双方恢复后继续原步骤；双方均离线亦不自动交易或刷钱。意外断线保席截止持久保存，恢复不续满。先意外离线时不能由单人改为7天手动暂停；须双方有效回桌解除系统挂起后，才可共同请求手动暂停。
- 明确确认“退出本局并认输”，记对手因认输获胜，不与财富胜混淆、不计永久积分；意外断线超过保席期则取消无胜者，避免把网络事故当主动认输。返回大厅只保席。终止时不回滚已完成交易，不自动执行尚未确认的出价/选牌/收益，也不奖励回合：未成交报价预留释放；待决牌/货物连同原属区进入只读的终态待决记录，仍纳入守恒，不向无权者公开。终态禁止再继续原选择。
- 登录401清除浏览器私牌并引导原邀请恢复；503或暂时失联保留最后确认画面与“同步中”，未确认动作保持原请求编号查账，不能自动新发一笔。房间、比赛、效果、选择和随机结果均有固定代际。
- 本机练习在后台／教学弹窗暂停计时，不产生服务器房间或永久战绩；恢复同一局面，退出回大厅再浏览器返回不重开旧练习。

## 9. 可见性与产品必备

- 公共：双方银两／货物／摊位／工具与朝向、手牌张数、牌堆张数、弃牌正面、共享行动条、当前决策人／期限、公开拍品及报价、终局原因。本人：手牌、待留弃牌、卦师／两仪灯选牌、堪舆师看到的牌。观众只取公共投影。
- 县丞明确公开双方手牌；花魁与貔貅袋公开牌面。它们结束后，公开事实可留历史，但不能以公共实体ID跟踪之后洗回暗堆的牌。隐藏候选、剩余牌序、秘密选择不得出现在公共日志、错误、气泡、备份下载或SSE中。
- 主桌中央行动条、左抽／弃牌堆、右公共货摊；**本人货物区在公共货摊正下，两区同在桌布内，以边界和标签明确区分归属**。六类货物顺序一致，主要显示图标×数量；普通／临时位、扩展容量、自己的钱、余步和临时位费用始终可知，看对手明区不代替本人摊位。
- **底部只承载本人全部手牌和真实已安装道具**，两者清楚分区。手牌使用连续可浏览牌列，无上一页／下一页；多牌可横向滚动或保持可辨识的叠放，不能裁掉不可达的牌。默认展示全部手牌，分类只能辅助查找。道具按最多3张真实实体分别展示牌面及竖直／横置状态，同名副本不得合并。用户提到增益／陷阱只是留场区的举例，不据此新增规则、空槽或虚构区域。
- **主牌面在短屏和窄屏仍保留艺术插画／货物图标、名称、类别和关键数值**；不得按尺寸替换成纯文字摘要按钮，也不得隐藏插画后只留名称。货物牌用图标×数量及买卖价减少重复说明，完整效果在详情可读；替代文本服务于无障碍或真实资源失败，不作为正常响应式布局。桌布、卡框、道具朝向与货物符号应共同形成可辨的桌游画面。
- 桌游房间按已定横屏使用；竖屏给转向提示、聊天／设置和明确退出，不能遮掉必要响应而让人不知为何超时。短横屏先压缩低频说明和多余间距，再重排或局部滚动，保留艺术牌面与决策出口；详情展示当前拍品／目标／成本，不能只显示“道具”二字。
- 准备室、正式房间、观战和练习分别核房号／邀请、聊天／本人气泡和未读、六主题、设置、声音、暂停、退出与恢复的适用状态；练习不造不存在的房间聊天。声音至少分出牌、收货／付款、轮到自己、需回应、倒计时提醒、终局；静音和启声沿共通设置。
- 练习电脑只读自己的合法视图；能完成选择、拍卖、反制、收市和再来一局。教学用同一规则，按“看牌→买卖→道具→回应→收市”分步，不以静态图鉴代替练习。
