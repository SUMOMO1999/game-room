## 终局与守恒结果

- **牌：110 = 82未抽牌 + 27弃牌 + 1已放置梅花令牌 + 0手牌 + 0待决查看牌。** 初始发出10张，随后取牌18次；其中24张货物牌、2张许可、1张查看后弃置的术士在弃牌区，1张令牌仍在A道具区。同定义没有超出真实份数：G19刚好使用4张，其余被使用的货物定义各2张。
- **货物：六类各6件全回公共区；双方库存均0。** 跨回合保留货物只发生在B3→B4、B5→B6、B7→B8；每次交易前都核对对应真实配方及公共余量。最低单类公共余量为1（A4买奇物后）。
- **银两：A64+B59+公共27=150。** A净获货物价差50，支付许可6及道具4，获得4次省步奖励：`20+50−6−4+4=64`。B货物价差36，支付许可3及临时格2，获得8次奖励：`20+36−3−2+8=59`。
- **扩展板：A1+B1+公共3=5。** 两人的普通容量都为8，额外临时格仍为收费格，没有被永久解锁。
- **行动：每回合最多4，均不超5；查看后留／弃没有二次计步，安装与激活分别计步。** 每次令牌只在竖直状态激活，回合末复位。本轨迹没有用满5行动，因此不宣称验证自动耗尽、免费连锁或在途响应。
- A于第15个玩家回合末首次触发；第16个玩家回合为B正常、完整的最终回合，奖励处理后比较64与59。未声称这条轨迹覆盖后手先到60、同分或回合中跨线后回落等其他分支。
