## 2. 版次、模式与关键时序

复核[发行商二版页面](https://keymaster.fun/products/parks-2nd-edition)所链接的[官方1.1规则书](https://cdn.shopify.com/s/files/1/1898/8501/files/Parks-2nd-Edition-1.1-Rules_Online.pdf?v=1755706180)，实际重读印刷页12～17。现有[M01～M10模式合同](modes.md)及[D01～D11项目解释](decisions.md)维持，以下是不能在实现中省略或混用的规则：

- 标准2～5真人；双人模式的Teddy为1组2棋子，官方单人为2组4棋子，普通练习电脑另属真人规则控制者。Teddy不成为账号、准备成员、聊天参与者或人类计分者。
- 双人Teddy只处理该模式的占位、天气及终点首到奖励，不偷摄影徽章、不移走公园／装备、不使用单人帐篷优先规则。单人Teddy的徽章、最右市场移除及帐篷优先按单人条文执行。
- 翻Teddy正面后，使用新顶牌的背面选择前／后棋子；单人每批各仍可行动的颜色组处理一次，先固定首张牌，再由玩家选先处理的颜色，不能把同色连续处理两次。
- 最后一名仍有在途棋子的真人，其余棋子各占独立回合直去终点；不能把两次移动共用一次装备限次或回合末容量检查。
- 季奖处理后再清水壶／营火、准备下一季与补市场；秋季奖励后直接终局。季奖与其派生机会属于指定真人责任窗口，不能直接按普通回合玩家授权。
- 露营替代所在普通地点的天气、地点效果、相应地点触发装备与摄影地点机会；到达前选分支，不能先领天气再反悔改露营。保留具体实体面／帐篷与外费、内部机会及季末转换。
- 9张志愿项目可用于所有人数模式，随机0～4张；官方单人采用3／4／5季奖阈值、无照片名次奖励，并给徒步等级，不造“击败Teddy”的胜负。照片并列、局部缺货及未追溯能力等官方未定边界沿已冻结D/M解释。

本次确认的是来源与设计一致；完整三季、逐装备组合、项目冲突及恢复仍须由实际自有规则核心验证。

## 3. 仍须保留的来源限制

**37件装备**的完整费用／触发／效果定义已有公开授权数字版教学静态事实，官方规则的地点触发与动作触发时序作为主依据；局部官方展示图已核。尚无全部37张实体卡图的第二来源目视比较，不能写“完整实体图独立通过”。不再为了找可复制引擎无界搜索；实施需把37定义逐一绑定自有可执行效果及行为测试，而不是解析展示字符串。

**露营实体双面关系**采用1/12、2/11、3/13、4/14。依据是非发行商公开数字对象明确的FaceURL/BackURL关系和8面图对应，可见实物四面无冲突；仍缺发行商配对表或逐块实物翻面独立证明，详见[配对记录](camping-pairing.md)。这是已采用的版本化项目关系，不能升级称官方实体认证，也不能初始化时另猜配对。

**志愿项目逐卡文字**来自已归档的授权数字版公开提示，版本`250417-1214`早于官方1.1；本次以官方印刷页14～17核玩法范围、触发框架与模式区别，未宣称9张实物文字均独立看图。原始公开脚本只读取规则事实，不引入执行代码或官方美术。既有二手资料限制仍按[来源记录](sources.md)维护。

这些限制不允许用空效果、错误默认或关掉可选模块代替完整实现。更强原始证据若出现，先比较实际差异，再版本化修订定义、行为和测试；已开局规则／内容引用保持。
