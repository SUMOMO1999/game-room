## 2. 将来逐项记录的共同字段

沿用[逐卡／物件模板](../../design/templates/card-definition.md)，但按本游戏适用项填写：

- 定义：固定 `typeId`、中文显示名／原名索引、版本、类别、标签、数量、版次、原始来源及具体页／图位置、校对状态。
- 公园：山／森林／太阳／水／野生动物的费用向量、印刷分值、即时奖励及后续选择。公园的事实简介属展示资料，与规则无关；独立查证重写，不复制原卡趣闻文案。
- 装备：费用、触发类别（地点进入／动作发生／获得资源／持续修正）、目标、付款、可选性、效果顺序、限次／重置、替换与叠加、新购后适用时点。不能从一枚图标猜全部触发条件。
- 热忱：完成谓词、进度证据、分支选择、能力及结算公式；不存能同时开启两分支的状态。
- 水壶：单枚效果、所属行、顺序选择、产水分配、使用后状态；行的季节限次由规则统一定义。
- 季节：在哪一季、比较的是背包现存／已游览牌印刷量／本季历史量、最低资格、并列和奖励顺序。不能只写“最多太阳”省略统计区域。
- 地点／骰子：完整面定义、连接与位置编号、合法性、基础机会、随机分布和公共摄影标记映射。
- 可选模块：露营实体双面关系、每面4营位、外层费用与内部动作；Teddy同张正反耦合、翻牌后新顶背选择、末端移动和模式差异；志愿项目的适用主体、事件、限制、费用和冲突顺序；单人阈值及等级。
- 实例：每局唯一`copyId`、区域、顺序、持有者、已用次数；资源ID与实体ID独立。隐藏牌堆不把顺序或可预测实例号投影给客户端。
- 交付：中文短文、详情长文、正背资源ID、来源／许可、无图替代、正常／不足／组合／恢复例子、实现行为ID与测试证据。

目录状态推进为“有来源 → 转录 → 独立核对 → 边界明确 → 行为及资源齐备 → 允许入局”。当前到转录及分范围核验阶段，未取得所有后续状态；不是靠填写`enabled:true`跳过。项目边界解释采用后，产品应明确为基于二版的数字适配规则，不能声称每个边界均有官方授权裁定。

## 3. 十种热忱的规则定义

依据官方1.1印刷页10～11，以下是中文规则转述；显示译名暂定。每种牌一张。初始目标公开，目标成立立即要求持有人二选一：能力分支或终局计分分支。无独立支付费用，选择不可改；未完成目标没有分支收益，不能同时取两边。所有计分仅看本人已游览公园、已购买装备或照片等指定记录，预订牌不计入已游览。

“费用中含某资源”看公园**印刷费用**，不是实际付了什么。使用野生动物替付或减免不会改印刷条件；按资源枚数的目标与按公园张数的目标分开。

1. **`passion.adventure` 探险 / Adventure**：游览2张有即时奖励的公园后完成。能力：之后游览即时奖励公园时额外掷步道骰；计分：每张已游览即时奖励公园1分。例：两张带闪电公园达标，一张普通高分公园不替代其中一张。能力每回合限制与连续游览按D03执行。
2. **`passion.birdwatching` 观鸟 / Birdwatching**：游览2张印刷费用至少含1太阳的公园。能力：之后每个公园少付1太阳；计分：每张已游览且费用含太阳的公园1分。例：一张需3太阳仍只算一张达标公园；不能把减免变成倒领资源。
3. **`passion.botany` 植物 / Botany**：已游览公园的印刷森林费用累计达到3。能力：获得森林时可以改得野生动物；计分：已游览公园每累计2个印刷森林得1分，取整。例：一张印3森林即可达标，终局合计5森林得2分。批量获得及每回合替换次数依D03。
4. **`passion.collecting` 收藏 / Collecting**：购买2件装备。能力：后续装备购买免费；计分：每件已购买装备1分。例：购买两件达标；季节奖励直接取得不计购买，按D03保留获得途径，不能仅看拥有件数。免费盲购与次数边界依D03。
5. **`passion.forestry` 林业 / Forestry**：游览3张印刷费用至少含1森林的公园。能力：之后每个公园少付1森林；计分：每张已游览且费用含森林的公园1分。例：一张印3森林不等于3张公园，与Botany不同。
6. **`passion.kayaking` 皮划艇 / Kayaking**：游览2张印刷费用至少含1水的公园。能力：之后每个公园少付1水；计分：每张已游览且费用含水的公园1分。例：用野生动物支付水费仍看卡上水图标。
7. **`passion.mountaineering` 登山 / Mountaineering**：游览3张印刷费用至少含1山的公园。能力：之后每个公园少付1山；计分：每张已游览且费用含山的公园1分。例：两张山公园不达标，无论山图标总数多少。
8. **`passion.rock-climbing` 攀岩 / Rock Climbing**：已游览公园印刷山费用累计达到3。能力：获得山时可以改得野生动物；计分：已游览公园每累计2个印刷山得1分，取整。例：印刷山总数3即可达标，与Mountaineering的3张区分；终局7山计3分。
9. **`passion.swimming` 游泳 / Swimming**：已游览公园印刷水费用累计达到3。能力：填水壶时额外掷步道骰；计分：已游览公园每累计2个印刷水得1分，取整。例：填一行放有两个水壶的槽是一次填行动，不凭两枚水壶擅自额外掷两次。
10. **`passion.wildlife` 野生动物 / Wildlife**：用野生动物支付一次拍照费用。能力：执行一资源换照片时，可用野生动物换2张照片；计分：每3张照片得1分，取整。例：仅获得野生动物不达标；8张照片加成2分。与摄影徽章的额外照片按D03组合。

上列牌本身的目标与分支有完整来源；段落中的限次／追溯／免费获得等历史缺口，现分别以[D02～D03](decisions.md#d02-新能力不重放旧动作)作确定的建议解释，非官方部分仍标注。每张牌的事实定义不等于已实现；技术计划需把这些目标不足、达标、分支和组合恢复例子映射到实际验证。

## 4. 已可读的公园实例

下列三张用来说明数据深度及做后续样板，不代表只做三张：

- **Grand Teton / 大提顿**：印刷3分，费用1山＋1森林＋1太阳；游览后即时掷步道骰。付款、卡归属和掷骰结果必须保存；断线不重掷。来源官方印刷页6。
- **Joshua Tree / 约书亚树**：印刷3分，费用3太阳＋1森林；游览后即时获2水，可支持同次公园行动继续游览或合法填水壶。来源印刷页7示例及63牌图。
- **Everglades / 大沼泽地**：印刷3分，费用4水；上述示例没有即时奖励。预订不计3分，游览后才计分。来源印刷页6～7示例及63牌图。

各例的费用向量都可由野生动物按基础规则替付；卡上明确野生动物费用时，普通资源不能逆向替付。不得用这三个规则示例生成其余60张的自拟费用。

## 5. 内容未决与接受标准

基础目录、全部可选面效果、9项目文本和4组露营关系已录；配对依据公开数字对象及8图对应，不冒称发行商验证，也不允许随机初始化另猜一组。[组件证据说明](components-list.md#6-证据限制与剩余核对)记录转录方法和版次范围，[规则证据](rule-evidence.md)保留原文没有写死的事项，[项目解释](decisions.md)和模式解释给唯一设计结果。BGG设计者关于地点／动作区别的完整检索文本已读，但原页直读未成功，不能标“在线官方勘误已核”。

目录结构校验覆盖总数、重复分布、唯一ID、费用及效果与来源链接；公园已增加独立逐图441字段复核，装备完整实体图、组合边界及2人／5人完整局仍不能由结构检查替代。原文无法裁定的行为必须采用有版本的明确解释后才实施，不让0、空字符串或随机参数填缺。已有代表插画与隔离页面，尚无可执行整局验证；展示文本／事实索引须转为逐定义绑定的自有规则行为。

## 6. 资源制作范围

以下为完整资源范围。Step 0曾交付4幅公园、2类装备代表及145项SVG映射，属于历史样板阶段。2026-10-11已补齐其余59幅公园和11类装备；当前共有**63幅独特公园＋13类装备＝76幅原创主体**，245种定义逐项映射为100项真实插画和145项原创SVG，详见[资源记录](../../assets/parks-v1.md)。美术全量完成与规则、整桌和发布验收分别记录：

- 公园：63幅独特风景主体＋1种统一公园卡框／牌背，名称、费用、分数和奖励由程序排版。先选山岳、湿地、沙漠3幅样板核风格与可读性，再补全；所有风景要对应实际公园特征。
- 装备：13种装备主体图，可用于37种规则牌；每张分别排真实费用、触发及效果，不用同名同图掩盖不同规则。统一装备框与牌背，不必让AI生成37幅只差小图标的插画。
- 热忱：10种可辨符号＋目标／能力／计分三种版式状态；不需要把每个状态都另生成一张位图。
- 水壶／季节／路线：以已核定面定义组合原创SVG图标，双面和重复实体分别计数；不得让缩略图或背面泄漏牌序。
- 露营／Teddy／志愿项目：8种露营面32营位＋3帐篷形状，21张Teddy正反耦合（移动3类、终点3类、背面2类可复用图标，仍逐张验份数），9项目的名称、规则与可辨符号，1单人阈值／等级参考。先做代表样板，再按完整目录全量排版；不为重复组合逐次调用AI生成图。
- 棋子和标记：5组颜色＋形状的徒步者、两态营火、资源5类、天气2类、骰子6面、摄影位置／徽章／先手、照片／相册、轮到本人／最近动作／待确认等呈现。
- 版面与声音：1套响应式路线、个人行囊／水壶板，适配六主题；基础动作音复用现有分类，缺少语义再原创合成，不采购素材服务。

本批使用内置imagegen原创水彩风景与装备物件，不采用官方卡面、BGA、艺术家照片或社区模组。NPS入口用于核对地貌特征，未下载其照片充当卡面；任何未来照片来源仍须逐图核对作者、许可和署名，不能对整个NPS图库统一宣布免费。

运行时使用15张整图WebP与15张整图传输缩略，分别6,740,206字节和1,167,082字节；原6幅PNG保持原像素和摘要。新增7张公园3×3图集及2张装备3×2图集均实测1536×1024，76主体具有不同分区及不同区域像素摘要，不共用同一区域充当不同公园。卡面通过SVG裁窗显示独立分区，不改画或栅格裁切；装备完整物件另有内层裁窗，防止留白露出相邻格。

独立检查实际解码全部30张WebP，核对245映射及76主体唯一性；内容14项与消费者5项测试通过。真实卡面消费者在1280×1000及844×360各显示76主体和245定义缩略，名称、费用与效果保留，装备完整区域及相邻格隔离通过。初次目视发现的装备裁切FAIL保留于本地证据，修复后的`browser-contained-r2/`另行记录。上述是资源与卡面消费者验收，不是全牌规则、整桌布局、真机、联机或发布验收。

对每种资源检查正常、选中、禁用、最新变化、动画、放大及失败替代；本游戏没有公共自由摆牌草稿，不额外开发拉密式拖牌预览。完整资源通过与样板通过分别记录。
