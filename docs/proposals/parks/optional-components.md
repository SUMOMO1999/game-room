# PARKS 二版全部可选模块清单

本清单覆盖用户要求首发交付的露营、双人 Ranger Teddy、官方单人和志愿项目。“可选”表示开局可开关，不表示从首发删减。版次为二版／规则书1.1；本页只承担规则材料事实，领域实际执行、资源和完整产品验收分别见[实施计划](../../plans/parks-v1.md#10-当前进度与交接记录)，不将目录齐全当作游戏已通过。

官方流程依据[规则书印刷页2～3、14～17](https://cdn.shopify.com/s/files/1/1898/8501/files/Parks-2nd-Edition-1.1-Rules_Online.pdf?v=1755706180)。全量定义来自[BGA匿名公开教程](https://boardgamearena.com/tutorial?game=parks)及该页加载的公开卡牌／效果说明；固定版本250417-1214早于官方1.1，不能替代后续勘误。全部逐项数据、来源位置与证据等级见[optional-catalog.json](optional-catalog.json)，动作、组合和恢复合同见[modes.md](modes.md)。

## 1. 露营：4块双面板、8面、每面4个营位

每局抽3块实体板叠放，每季使用最上面的一面。营位由左到右编号；已放帐篷的营位不能重复使用。外层兑换费用先支付；购买装备、拍照等内部动作仍需各自付费。复合营位全部基本动作如何完成、普通资源替付及库存限制，采用[模式合同M05](modes.md#5-露营完整流程)的明确项目解释。

“任意2资源”的支付与领取均可选五类资源，包含野生动物，可同种；依官方p5通用资源定义，不另增四类限制。指定山／森林／太阳／水的营地外层费用不允许野生动物替付；营地内的购装／拍照／游览仍沿原动作替付规则。

## 3. 志愿项目：9张、每种1张

可用于1～5名真人的对局，可不开启或随机加入1～4张；1／2／3／4张分别对应Beginner／Intermediate／Advanced／Extreme，挑战箭头数等于所用项目数。所有选中项目共同生效。规则原文是游戏中的限制，不是局末另交一次任务；公共适用、优先级与组合裁定见[模式合同M07～M10](modes.md#6-志愿项目与规则修正)。

1. **节约用水 / Water Conservation**（`volunteer.water-conservation`）：自己的回合中只要获得过太阳，就失去1水（有水可失去时）。
2. **野生动物保护 / Wildlife Conservation**（`volunteer.wildlife-conservation`）：背包中的野生动物任何时候都不能超过1。
3. **可持续交通 / Sustainable Transportation**（`volunteer.sustainable-transportation`）：只能游览自己的预订公园。
4. **负责任消费 / Responsible Consumption**（`volunteer.responsible-consumption`）：每购买1件装备，背包容量减少1资源。
5. **环境研究 / Environmental Studies**（`volunteer.environmental-studies`）：必须持有摄影徽章才可以取得照片。
6. **气候行动 / Climate Action**（`volunteer.climate-action`）：天气不再摆放太阳；水天气仍放在原本的水位置。
7. **减排 / Reduce Emissions**（`volunteer.reduce-emissions`）：从本局公园牌中移除全部印刷2分和3分的牌。 依已核63公园目录共移除24张，剩39张。
8. **无痕山林 / Leave No Trace**（`volunteer.leave-no-trace`）：每季开始时营火保持熄灭。
9. **碳补偿 / Carbon Offsetting**（`volunteer.carbon-offsetting`）：每次游览公园之前，额外支付1山或1森林。

九张逐卡规则来自[公开卡牌提示](https://x.boardgamearena.net/data/themereleases/current/games/parks/250417-1214/modules/pks-cards.js)，中文为独立转述；未把公开实现当作可复制的代码，也未将其说成9张实体牌都已完成第二来源目视。

## 4. 帐篷3枚与单人参考1张

3枚帐篷开局分别放在普通路线第**5、7、9格**上方；起点为0，第5格是固定Parks。位置由官方设置图放大核对，并与公开教程展示映射一致。季末按原位置放回，不随机换成3个新位置。

单人参考卡不额外给玩家一个动作，它汇总Teddy的干扰方式与单人季节门槛：

1. 露营开启时，Teddy把遇到的帐篷放到最右空营位，自己不获得该营位收益；此分支与普通地点收益替代关系见模式合同。
2. 普通天气归池；摄影位置使Teddy取得徽章；公园／装备动作分别移除最右展示牌并右移补位。
3. 单人春／夏／秋季奖励门槛分别为3／4／5，统计量仍是当季季节块所指指标；夏季不统一解释成背包资源，秋季看已游览公园印刷量。
4. 单人不使用照片排名奖励块；30／35／40／45／50分分别对应Dayhiker／Trekker／Explorer／Adventurer／Trailblazer，项目箭头另列。
