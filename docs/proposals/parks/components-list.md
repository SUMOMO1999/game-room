## 2. 水壶标记24枚

共6种定义，重复数已从24条静态条目逐枚累计；每种效果要先用一枚刚获得的水填入其所在行才可执行。每行最多放2枚标记、每季填1次；照片和野生动物交换仍需要额外支付，不能把水壶图标译为免费领取。

1. 获得1山：**5枚**，参考编号1～5。
2. 获得1森林：**5枚**，参考编号6～10。
3. 获得2太阳：**5枚**，参考编号11～15。
4. 执行公园动作：预订1座或游览任意多座可支付的公园：**3枚**，参考编号16～18。
5. 支付1资源拍1照片：**3枚**，参考编号19～21。
6. 支付1资源换1野生动物：**3枚**，参考编号22～24。

合计5＋5＋5＋3＋3＋3＝24。来源：公开教程静态水壶定义；官方印刷页8的示例可读到山、森林、双太阳、公园与照片图标，其中基本机制已由原书说明。

## 3. 季节块12块

春、夏、秋各4块，每种1块；开局分别从每季4块中抽1块。比较值至少为1才有资格；并列最高者均得完整奖励。春季奖励免费，夏季奖励都是掷骰2次，秋季奖励都是3分。来源：公开教程的12条静态季节定义，通用结算规则为官方印刷页12。

### 春季

1. 背包内太阳数最多 → 免费取得装备牌堆顶牌。
2. 背包内水数最多 → 获得1水壶标记。
3. 背包内森林数最多 → 预订1公园。
4. 背包内山数最多 → 免费获得1照片。

### 夏季

1. 已拥有装备的印刷太阳费用合计最多 → 掷2次步道骰并分别结算。
2. 背包内野生动物数最多 → 掷1次步道骰并结算、掷1次步道骰并结算。
3. 已拥有水壶标记数量最多 → 掷2次步道骰并分别结算。
4. 已游览带即时奖励公园张数最多 → 掷1次步道骰并结算、掷1次步道骰并结算。

### 秋季

1. 已游览公园印刷太阳费用合计最多 → 获得1分、获得1分、获得1分。
2. 已游览公园印刷森林费用合计最多 → 获得1分、获得1分、获得1分。
3. 已游览公园印刷山费用合计最多 → 获得1分、获得1分、获得1分。
4. 已游览公园印刷水费用合计最多 → 获得1分、获得1分、获得1分。

夏季“装备太阳”按装备的**印刷费用之和**比较，不是当前背包太阳，也不是当时实际支付量。水壶目标比较已拥有的标记枚数，不是已填水的行数。官方印刷页2的开局示例写明太阳位于装备；秋季资源按已游览公园的印刷费用累计，预订牌和背包不混入。夏季带即时奖励公园比较的是张数，不是即时奖励动作次数。

## 4. 地点与固定公园

**8块可移动地点板＋主板中央固定Parks地点＝9种地点动作。** 官方印刷页2～3主板图在第4与第5个可移动地点槽之间印有Parks，8块地点正面随机摆在其余8槽；它不是第9块漏列组件。公开教程的初始路线也固定中央Parks。

1. 获得1森林。
2. 获得1山。
3. 获得2太阳。
4. 获得2水。
5. 支付1资源换1野生动物。
6. 获得1水壶标记，或支付1资源拍1照片。
7. 购买1件装备。
8. 掷1次步道骰并结算。

固定中央Parks：预订1公园，或游览任意多座当时可支付的公园；这两个模式按公园动作规则选择。8块地点始终行动面朝上，其装饰背面不另算一套可选动作。

## 5. 步道骰6面及摄影位置映射

官方印刷页2提供完整摄影标记对照，页10说明掷骰实际所得。骰面本身没有额外支付要求；摄影标记只是根据该面放到对应地点，因此野生动物面／水壶面与该地点原动作文字不同。

1. 获得1森林；季节设置摄影标记放在森林地点。
2. 获得1山；季节设置摄影标记放在山地点。
3. 获得2太阳；季节设置摄影标记放在2太阳地点。
4. 获得2水；季节设置摄影标记放在2水地点。
5. 获得1野生动物；季节设置摄影标记放在1资源换野生动物地点。
6. 获得1水壶标记；季节设置摄影标记放在水壶／照片地点。

六面各出现1次，公平六面骰的设计抽样概率各为1/6。骰面没有购买装备或Parks动作。
