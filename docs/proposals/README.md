# 新游戏提案

朋友从[分类入口](../design/game-design-template.md)选择：414、扑克、麻将等复制[固定牌类模板](../design/templates/fixed-deck-game.md)；不同牌、角色或地块各有行为的游戏复制[桌游类模板](../design/templates/tabletop-game.md)，按[逐卡定义](../design/templates/card-definition.md)补本轮全部独特类型。飞行棋可用轻版，卡牌章节写不适用。

把文件放在这里，例如 `414.md`；多种内容可放在同名子目录，通过目录索引关联每份定义。优先填写“朋友填写”部分，保留技术部分给维护者。没确定具体版本时先按[游戏名拆解指引](../design/from-game-name.md)圈定范围。

这里的文件是讨论中的提案。规则确认后，维护者在 [正式游戏设计](../design/games/) 中建立版本化文档，按[Step 0](../design/resource-stage.md)验证资源与操作，再实施与验收。仅添加提案不会使大厅出现新游戏；新效果也不能只靠填文本自动执行。

也可以直接发送设计文件，无需自己操作 Git 或运行代码。提交方式见 [CONTRIBUTING.md](../../CONTRIBUTING.md)。
