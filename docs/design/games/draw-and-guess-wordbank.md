# 你画我猜分类词库设计

2026-10-07。词库是持续维护的内容资源，服务于[经典模式](draw-and-guess.md)，按类别、难度和别名管理。用户已确认前端配置页、可扩充分类与词条、伙伴直接编辑公共库、保留修改记录及恢复版本。首版以原创中文词条和伙伴录入为来源，不抓取商业词库，不依赖 AI 生成或识图。本页定义结构与代表性样例，首发七基础类各80词／共560词及管理页已上线，见[实现与发布范围](../../development-drawing.md)。真人逐词试画与后续扩充继续进行。

## 分类和难度

每个词有一个主分类，可另有多个检索标签。主分类决定房间选择范围和本题公开分类名；标签只用于内容维护，不自动改变规则或公开题目。跨分类的同义词合并成同一词条，不靠换分类重复出题。

- `daily` 日常物品：雨伞、牙刷、闹钟。
- `nature` 动物与植物：熊猫、向日葵、仙人掌。
- `food` 食物与饮料：饺子、冰淇淋、珍珠奶茶。
- `action-job` 动作与职业：游泳、刷牙、消防员。
- `place-transport` 地点与交通：自行车、机场、火车站。
- `screen` 影视与动漫：哆啦A梦、孙悟空、奥特曼；只用名称供真人画图，不采用商业角色图片、商标图或影视截图作素材。
- `idiom-abstract` 成语与抽象概念：画蛇添足、守株待兔、时间；词义难表现时只放挑战难度。
- `friends` 朋友梗与自定义：朋友录入自己的昵称、共同经历或约定词。初始为空，不计基础词量；不自动导入账号姓名、聊天或日历内容。默认私人包，作者明确发布公共副本才供其他成员使用；两者均不自动上传GitHub或进入匿名静态资源。

难度分 `easy` 简单、`normal` 普通、`hard` 挑战。简单词主要是能直观画出的具体物件或动作；普通允许职业、地点及组合概念；挑战包含成语、抽象概念或需要特定知识的名称。长短不直接决定难度，至少由维护者试画／讨论后判断。

首发计划前七类各至少80条，共至少560条审核词，由维护者整理。默认前五类的简单与普通每类至少64条；影视动漫和成语抽象不强凑简单词，其余可选。朋友词包单独添加，不计入基础库齐备数量。上面的21个名称是分类样例；完整560条位于版本化种子目录，已做数量与程序校验，真人逐词试画不冒称完成。

## 前端管理入口与权限

大厅提供词库入口；房间设置只负责选择内容版本／分类／难度、显示数量和跳转管理。词库编辑页允许长列表滚动，手机游戏主屏仍一屏操作。

所有有效棋牌成员可以新增、编辑和发布公共分类及词条，无管理员审核关卡；程序校验和本人预览确认仍必需。公共指生态成员共用，匿名访客不可写。公共草稿有CAS版本，修改记录可见，发布版不可变；恢复旧版生成新草稿，经确认发布新版本，不抹掉后来记录。冲突保留本人编辑，不自动整包覆盖。

成员也可建立长期私人词包，仅所有者管理和读取；当前房主只能选择本房内容，不能修改别人的私库。私人库由本人作为房主采用，或明确发布公共副本后由朋友选择。词库编辑权不赋予任何房间席位、房主、画笔或本题候选权限。包／分类ID来自数据，不固定为当前八种。

## 词条的完整定义

每个词条保存以下字段，未来数量增加沿用结构；新增判词方式或题型仍要另改规则和验证。

- `id`：稳定编号，改名、重新分类或排序不换编号；确实换概念时新增编号。
- `answer`：显示答案，1～32个Unicode字符、至多128 UTF-8字节，规范化单行，无控制字符或不可见混淆字符。
- `aliases`：至多8个明确认可的称呼，与正文同长度和字符限制；没有则空数组。默认不接拼音、错别字、子串或泛称。
- `category / tags / difficulty / language`：主分类、至多8个维护标签、难度、首版语言 `zh`；标签不上题目提示。
- `packId / definitionVersion / source / status`：所属内容包、定义版本、原创或获授权的来源说明、`draft / reviewed / retired` 状态。只有 reviewed 能入新局。
- `hintLength`：显示答案经NFC规范化后的Unicode码点数，字母及数字也各计一位；别名长度不同不改变提示长度。词条不接受组合控制字符、零宽连接或不可见填充来影响长度；提示不是答案前缀或内部词条ID。

例子：`dg-base-bicycle` 的正文“自行车”，别名“脚踏车”“自行車”，主分类 `place-transport`，标签“交通工具”，难度 `easy`，语言 `zh`，来源“原创整理”，定义版1，提示3字。猜“脚踏车”正确；猜“车”“zixingche”“这是自行车”不匹配。是否加入“单车”作为别名要确认当地用法歧义，不自行扩大接受范围。

另例“熊猫”可明确认可“大熊猫”；“熊”“猫”“熊猫宝宝”不自动正确。标签“动物”“中国”不当作认可答案；没有把概念对应的全部上位／下位词自动当别名。

## 分类选择和抽题

等待页显示分类、难度、基础包版本、自定义包名称、筛选后有效唯一词数和本局所需候选数，不给普通成员下载私人完整词包。仅当前房主选择本房采用版本；其他成员编辑公共库不等于修改该房配置，作者或中心管理员不因此取得房间权限。原词包作者事先知道内容是自定义玩法的已知边界。

按所选包、主分类和难度筛选 reviewed 词条，以稳定ID与规范化正文／别名排歧去重。候选总数至少为 `玩家数 × 每人绘画次数 × 3`：8人每人2次需要48条，8人每人5次需要120条。少于需求禁开局，明确建议扩大范围、减少轮数或补充词条，不偷偷重复或取消过滤。

默认把所有符合条件的唯一词条等权混合，分类词数多则出现概率更高，不保证各分类等量。开局服务器无放回预采样整局候选并保存随机分组题序，最多120条完整定义；每题开始只向当前画者投影本组3个。刷新不重抽，未选词不重复出给后面的画者。画者只能选候选，不能自带题目或指定词条编号；伙伴在管理页扩充分类和词条，从之后明确选用的版本生效。

首版不承诺跨局／跨房绝不重复。以后可以加近期避让，但要另定保存期限、多人公平性、词库不足时的降级规则和版本，不能为此无限保存个人答题记录。

## 朋友自定义词库

有效成员在管理页添加／编辑公共包或本人的私人包，支持逐行输入“答案｜别名1｜别名2”并预览分类与难度；不接外部URL、脚本、压缩包或图片。单次批量建议5～200条、输入至多64 KiB，不是整包总容量；完整包的词量／字节／版本额度见[实现与发布范围](../../development-drawing.md)。普通中文用词不需要填写技术字段，程序分配包与词条编号；与基础词同样做字符、别名和重复检查。

重复或歧义要逐行指出，不能静默吞掉整批内容。任何一个答案／别名经判词规范化后不能在同一可选词库集合中指向两种概念；同义概念可合并，并保留一个稳定ID。无效行不能入局，修改和删除需确认受影响行，不清空其他包或真实资料。

输入先为 draft；程序完成字符、规范化、别名和重复检查，受权成员预览并明确发布后，该不可变版本标 reviewed、可供有权读取的人开局采用。公共库不再等待维护者批准，私人库只本人操作；初始种子仍由维护者逐条整理。待确认或无效草稿不取代此前可用版本，草稿revision与发布head分别保存。恢复旧版同时守当前head和当前草稿revision，不静默丢弃伙伴未发布工作。

可选择“基础＋朋友词包”或“仅朋友词包”。仅朋友包仍满足整局候选数，不因最低录入5条就保证能开局。全部分类关闭、筛选后为零、超数量／字节上限或未审核词均有清楚说明。

开局后不能修改本局冻结词条、别名或难度。公共／私人长期词库可继续维护，新的发布不改变已有房间选择或正在玩的题目；本房冻结副本依房间期限回收，原长期词库按内容额度／版本保留策略维护。私人内容不自动分享、上传GitHub或写共同资料；暂停局的冻结定义仍可恢复。

## 持续丰富和版本管理

维护流程为：发现缺项／伙伴直接编辑 → 分分类与难度 → 查重复和别名歧义 → 检查能否画出 → 预览校验 → 明确发布 reviewed 新版本。词库数量、各类及难度分布有统计；优先补薄弱分类，不只堆已有大类。初始560条做逐条内容复核，后续伙伴共编不新增管理员审批步骤。

内容包使用独立 `packVersion`，程序和判词规则另有版本。每局保存冻结的答案、别名和本局候选定义，更新部署不改变旧局结果。退役词从之后采用的版本中移除，进行或暂停局继续冻结定义；更改正文／别名须增定义版，不能按现行文件重算旧题。等待局采用确定版本，版本被停用时提示房主重新选择并清准备。

新增类别需要分类目录及样例完整、筛选与公开提示可读；新增普通词无需改引擎。要引入多答案题、日语题、句子题、图片题或谐音规则，则先补规则与验收，不能只塞入数据声称兼容。

基础词库可以公开维护，但本局候选、抽词顺序和私人包受游戏投影保护；不依赖“别人永远不知道词库”防作弊。看过电影或写过朋友梗带来的知识差异用房间分类选择处理。

## 资源小样与质量检查

Step 0先使用各类至少3条代表词，包含最长词、别名长度不同、繁体、英文／数字、难画的抽象词、近义但不相同的词，以及一份明确为虚构的朋友包；样例补上完整字段后才能用于原型。不要提前画出答案插画，避免把绘画玩法变成选图。

完整接入前核对：稳定编号唯一、分类存在、状态正确、限长和别名冲突、字符计数、规范化的正确／错误答案、筛选所需数量、无放回候选、私有投影、跨版本恢复、禁用包及自定义失败反馈。词库审核通过和手机上屏通过分别记录，不把JSON能解析当作词库好玩。

朋友参与设计或录入只需提供“分类、词语、认可别名、觉得简单还是难、容易歧义的地方”，不要求跑代码。配置页实现后可直接管理公共库和自己的私库；当前仍在计划阶段。定时自动补充、自动抓取或自动发布不在本设计中。
