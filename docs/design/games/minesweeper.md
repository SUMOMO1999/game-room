# 扫雷：经典单人模式设计

2026-11-27。**用户已确认**：单人模式，参照经典 Windows XP 扫雷；提供初级、中级、高级，分别为 9×9／10 雷、16×16／40 雷、30×16／99 雷；第一次点开的格子保证不是雷，但可以是数字，不保证空白开局。**本稿为设计，尚未实现或验收**。问号标记、快速开格、计时、本机保存和触摸适配按下文形成完整设计约定，不冒充逐项获得用户确认。

实现与验收见[单人扫雷实施](../../plans/minesweeper-v1.md)。

游戏标识拟为 `minesweeper`，规则版本拟为 `minesweeper-classic-v1`。采用[桌游模板](../templates/tabletop-game.md)轻版：材料是方格、地雷、数字和标记；牌组、角色、电脑对手、回合轮转、交易和积分货币均不适用。共通设置、声音、导航和布局分别参照[平台设计](../platform.md)、[房间布局](../room-layout.md)与[操作体验](../gameplay-experience.md)。本次仅补充设计文件，后续按[技术计划模板](../../plans/game-implementation-plan-template.md)评审，再进入[Step 0](../resource-stage.md)和完整实现。

## 1. 版本、难度与本轮范围

一位玩家根据数字判断地雷位置，打开全部非雷格即获胜；打开任意地雷立即失败。插旗是辅助记号，不要求先把所有雷标出来。

| 难度 | 参数标识 | 列数（宽） | 行数（高） | 地雷数 | 非雷格数 |
| --- | --- | --- | --- | --- | --- |
| 初级 | `beginner` | 9 | 9 | 10 | 71 |
| 中级 | `intermediate` | 16 | 16 | 40 | 216 |
| 高级 | `expert` | 30 | 16 | 99 | 381 |

- 首次进入默认初级，后续记住本人在当前浏览器最后选择的难度。有未结束存档时优先提供继续入口，不用偏好覆盖旧局。
- 三档规则相同，只改变尺寸与雷数。高级固定为 **30 列、16 行**，横竖屏不转置棋盘或重编号。
- 本轮只有单人随机局。单人本身即可独立练习，不再另造一套简化规则或电脑陪玩。
- 从大厅所属游戏的单人／练习入口进入，不需要账号、邀请、准备或房主开局。不会创建朋友房间、占用正式席位或产生联网聊天。
- 本轮不加入自定义尺寸、无猜局生成、提示、自动解题、撤销开格、复活、每日挑战、多人竞速或跨设备排行榜。经典随机局可能遇到必须猜测的情况，不保证每局都能仅靠逻辑解完。
- 本机个人纪录见第 5 节，不接平台正式战绩或永久娱乐积分。

## 2. 棋盘、材料与信息

### 2.1 格子及相邻关系

- 棋盘为矩形方格，坐标用从 0 开始的 `row / column`；稳定格子编号为 `row × columns + column`，在同一局内不变。
- 相邻指水平、垂直、斜向最多八格。角格最多三个邻格，边格最多五个；左右两端不相连，不跨行绕回。
- 一个格子实际内容为地雷或非雷。非雷格的数字为相邻地雷数，取值 0～8；0 显示为空白。
- 玩家可见的业务状态为：未打开、插旗、问号、已打开。旗和问号只存在于未打开格，互斥；已打开格不可重新盖上或加标记。
- 每格最多一枚地雷。插旗不移动、增加、排除或销毁真实地雷，数字也不随标记变化。

### 2.2 首次开格与随机布雷

- 进入新局时先生成空的可见棋盘，不预先向玩家确定或展示雷位。第一次有效开格时，在其余格子中等概率、无放回抽取固定数量的雷，并计算数字。
- **只排除本次打开的那个格子**，相邻格仍可有雷；首次可能打开 1～8，也可能打开空白并展开。布雷不使用无猜局筛选或额外的安全九宫格。
- 首次开格前可以标记。插旗或问号不触发布雷、不启动时钟；已有标记不影响之后的雷位分布。
- 点旗格不算有效开格；必须先取消旗。问号格可以直接打开，移除问号后按正常开格处理，也可以成为首次开格。
- 布雷、首次揭示、展开结果、开始时间和存档作为同一次状态变化处理。刷新、重进、调整窗口或重复收到同一输入，都不能重新布雷。
- 首次之后不再挪雷。新开格或快速开格踩雷时照常失败，不追加安全保护。

### 2.3 信息边界

进行中只显示已打开数字、玩家自己的标记、剩余雷数估计和用时，不通过颜色、读屏名、提示或预览透露未开格的真实内容。未开格的可访问名称只能是坐标和“未打开／旗／问号”。

本轮采用本机规则和存档，浏览器内部必须持有雷位，不能承诺防止查看开发者工具或篡改个人纪录。完整状态不发送到公开日志、聊天或账号资料，也不把本机结果作为可信竞技成绩。

## 3. 从进入到结束的完整流程

大厅单人入口 → 继续已有局，或选择难度开始新局 → 未开局棋盘 → 第一次有效开格并开始计时 → 反复开格／标记／快速开格 → 胜利或踩雷失败 → 查看结果 → 同难度再来一局、换难度或返回大厅。

| 阶段 | 可执行动作 | 计时与离场 |
| --- | --- | --- |
| 待开格 `ready` | 标记、取消标记、首次开格、重开、换难度、退出 | 计时为 0；尚无雷位；可保存已有标记 |
| 进行中 `playing` | 开格、标记、快速开格、查看规则、重开、换难度、退出 | 正向计时；没有行动期限或超时惩罚 |
| 胜利 `won` | 查看最终棋盘、结果与纪录；再来、换难度、退出 | 停表；棋盘只读 |
| 失败 `lost` | 查看踩雷及错误旗；再来、换难度、退出 | 停表；棋盘只读 |

没有轮到谁、过牌或无合法行动判负。无法确定下一步时由玩家继续判断或猜测，不自动行动或结束。未完成就重开称“放弃本局”，与踩雷失败区分，不记录为胜利或个人纪录。

在已存在标记或已开始的棋盘上，笑脸／重新开始和 F2 均先确认放弃；取消保留原局。空白待开格局和已结束局可以直接开始新局。新局创建新 `gameId`，重新清空雷位、标记、打开计数和时钟；“再来一局”沿用难度，不复用原雷图。

切换难度先说明将离开当前局、已保存进度仍可续入并确认；若目标难度已有未结束存档，应提供“继续该局／重新开始／取消”，不能静默覆盖。取消整个切换保留当前局；明确切换后，当前难度已成功保存的最近进度仍保留，可稍后返回继续。只有对某一难度明确重新开始，才替换该难度的旧局。

## 4. 行动与经典规则

### 4.1 打开一个格子

1. 只允许在 `ready / playing` 阶段打开未插旗且未打开的有效坐标。
2. 若为首次有效开格，先按第 2 节固定雷图和开始时间。
3. 若为雷，立即进入失败；若为数字 1～8，只打开该格。
4. 若为 0，打开与其八邻连通的全部未插旗 0 格，以及这些 0 格边界的未插旗非零数字格；问号可随展开被移除并打开。
5. 插旗格保持覆盖，即使它实际上是安全格；不会因展开替玩家纠正错误旗。取消旗不会自动展开，之后仍须主动开格或快速开格。
6. 一次展开中的同一格只处理一次；展开只依据雷图，不跨过数字边界继续传播。动作完成后统一检查胜负。

鼠标按下时的凹陷仅为预览。正常释放并确认命中才开格；拖出目标、取消指针、滚动或失焦取消预览，不改变棋盘。点击已打开空白不产生动作；点击数字只通过下文定义的快速开格手势操作。

### 4.2 插旗与问号

- 默认启用经典问号标记。同一格的标记操作按“未标记 → 旗 → 问号 → 未标记”循环。
- 设置中关闭问号后改为“未标记 ↔ 旗”，已有问号清为未标记，已有旗保持。重新开启不会凭空添加问号。此操作不重新布雷或重置时间。
- 已打开格和结束后的棋盘不可标记。旗和问号均不会验证雷位正确与否，也不会因标错立即失败。
- 左侧计数显示 **总雷数 − 当前旗数**；问号不扣数。它表示估计，不能当作真实未找到雷数。
- 允许旗数超过雷数，计数可以为负。负数必须完整可读，必要时扩展显示位数，不截断或把负数归零。
- 旗数等于雷数、计数为 0、全部真实地雷被插旗，都不能单独触发胜利。

### 4.3 数字周围快速开格（双键开格）

- 目标必须是已打开的数字格 1～8，周围旗数必须**恰好等于该数字**；多旗、少旗、空白或未开格均不执行。
- 满足条件时，一次打开周围所有未打开且未插旗的格子，包括问号格；安全空白再按相同规则展开。
- 只比较旗的数量，不验证旗是否插对。错误旗可能使未标记地雷被打开，立即失败，不能悄悄拒绝并替玩家指出错误旗。
- 快速开格是一次原子动作。若本次目标集合包含地雷，先判失败，不能因为某个循环顺序先打开最后一个安全格而判胜。安全目标可正常揭示，失败展示全部地雷；多个触雷目标按格子编号最小者作为唯一红底触雷格。
- 没有可打开目标时不产生变化。前提不满足时只给轻提示，不改变数字、标记、时钟起点或雷图。

## 5. 胜负、计时与本机纪录

### 5.1 结束条件和结果

- **胜利**：一次行动结束后，未触雷且已打开非雷格数等于 `行数 × 列数 − 雷数`。本轮分别为 71、216、381 格。
- 胜利后剩余地雷自动显示旗，剩余雷数显示 0；这是结束呈现，不是要求玩家预先全部插对。显示笑脸胜利表情、难度和完成用时。
- **失败**：非首次开格或快速开格打开地雷，立即停表。触雷格红底，其他未标记地雷显示雷；正确旗保留，插在安全格上的错误旗显示叉，未打开的其他安全格保持覆盖。
- 失败和胜利后禁止继续改变棋盘，没有撤销、复活或重试原图；可查看最终状态或重新随机开局。

### 5.2 时钟

- 第一次有效开格时从 0 开始，插旗、问号、按下未释放和无效操作均不启动。按正向经过秒数显示，不借用多人游戏的 30 分钟倒计时。
- 棋盘保留经典三位红色数字显示，0 补为 `000`，显示上限 `999`；达到上限继续游戏，不判负。内部继续记录真实用时，结果页与个人纪录显示完整秒数。
- 本稿不设置暂停。打开设置／规则、窗口失焦、切到后台、刷新、关闭页面后恢复，都继续计算从首次开格到结束的经过时间；界面在进入游戏时说明“离开期间仍计时”。不把后台计时任务是否实际运行当作计时依据。
- 胜负动作固定结束时间和完整用时，刷新结果页不能继续加时。设备时钟被调整导致的异常不得出现负数或新增最快纪录；具体检测与时间源在技术计划中明确。

### 5.3 个人最快纪录

- 每档只保存一个本机最快完成秒数及完成日期；只有正常胜利才有资格更新。按完整用时向下取整的秒数比较，同秒保留原纪录，显示并列个人最佳即可。
- 三档分别比较，不把初级和高级混排。失败、放弃、待开格和存档异常不更新纪录；重复载入同一胜局不重复结算。
- 纪录属于当前浏览器的本机游戏数据，不填写公共姓名、不上传服务端；清理站点数据可能丢失，不承诺跨设备同步或防作弊。
- 设置中提供查看与明确确认后清除纪录；清除纪录不改当前棋盘或重新开始。

## 6. 页面、鼠标、键盘与触摸

### 6.1 经典外观与共通工具

- 视觉以灰色凸起方格、打开后的平格、彩色数字、红色计数器和中央笑脸为核心。数字 1～8 各自可辨，空白不显示 0；颜色之外保留数字及读屏文字。
- 棋盘上方保持“剩余雷数估计｜笑脸重开｜计时”，附近显示当前难度。待开格为普通笑脸，按住有效开格目标时为紧张表情，胜利为墨镜笑脸，失败为叉眼表情；表情不取代结果文字。
- 顶部沿用“状态区｜设置 → 退出”。设置收入难度、问号开关、声音、规则、纪录；结果区直接提供再来和返回。规则、设置和重开确认遵循单层弹窗，不相互堆叠。
- 不仿造 Windows 系统窗口、开始菜单或无关菜单。格子、旗、雷和表情自行用代码／矢量绘制，不提取 Windows 程序资源。
- 开格和标记反馈短促、结果清楚；大面积展开直接呈现最终状态，不强制等待逐格动画。每次行动最多一段反馈音，胜负音优先，静音仍有文字和图形。

### 6.2 输入映射

| 输入设备 | 打开 | 标记 | 快速开格 |
| --- | --- | --- | --- |
| 鼠标／触控板 | 左键释放 | 右键 | 已开数字上同时按住左右键，再释放触发一次 |
| 键盘 | 方向键移动焦点，Enter 打开 | F 循环标记 | Space 对焦点数字执行 |
| 手机／平板 | “打开”模式下点按 | “标记”模式下点按；或长按循环标记 | 对已开数字双击／双点 |

- 同时左右键必须合并为一次快速开格，抑制该手势派生的单次开格、右键标记和浏览器菜单；数字上的鼠标双击也可执行同一动作。
- 键盘 Space 不滚动页面，重复按键不会误发多次；F2 按第 3 节重开，输入框和设置内不拦截这些快捷键。棋盘采用单一 Tab 入口及可移动格子焦点，不让 480 格成为 480 次 Tab 停靠。
- 触摸默认“打开”模式，始终可见“打开／标记”切换和当前模式。模式是输入偏好，切换不改变任何格子。新局和重新进入页面默认回到打开模式，避免沿用隐藏偏好误操作。
- 长按默认 400 毫秒，成功后抑制抬手 click，只执行一次标记；移动超过 8 CSS px 或发生指针取消便取消长按，进入滚动。按下时即显示目标预览，避免把等待误认为无响应。
- 双点已开数字不会把第一次点按当作普通开格。触摸屏不要求模拟同时左右键，也不自动把单点数字变成快速开格。
- 滚动、双指缩放或旋转时取消尚未确认的手势，不误开格、不重复标记。浏览器上下文菜单只在棋盘内按需阻止，页面其他区域保留系统行为。

### 6.3 尺寸与方向

- 按新桌游默认约定，手机游戏主屏采用横屏；竖屏显示转向提示并保留设置和退出入口，规则阅读可竖屏。转向提示不暂停计时，不清棋盘。
- 电脑优先完整展示棋盘；手机高级局允许棋盘容器双向滚动。保持方格等宽等高和正确坐标，不为了塞入 30 列而缩到无法辨认。
- 鼠标环境格子目标至少 24 CSS px；触摸环境格子至少 32 CSS px，模式切换、设置、退出和确认按钮至少 44×44 CSS px。更小可用视口通过局部滚动处理，头部计数、模式和退出持续可达。
- 可提供显示缩放以增大格子；缩放、滚动与转屏只改显示，保留雷位、打开状态、标记、当前焦点及仍有效的可视区域，不换难度或生成新局。
- 读屏播报行列、未开／旗／问号／空白／数字、难度、估计雷数和结果；计时器不每秒打断读屏。胜负与非法动作有独立通知。

## 7. 本机保存、退出和异常恢复

- 保存位置为当前浏览器的本机存储，不上传账号。每档保留一份最近进度，结束局可留作结果查看；每档个人最佳独立保存。
- 每次有效开格（含整个展开）、标记、问号开关引起的标记变化、新局和结算，都按完整快照保存；先固定结果再写入，不能恢复成只有部分展开的新状态。
- 快照至少包括 `gameId`、规则版本、存档格式版本、难度、尺寸与雷数、阶段、固定雷位或未布雷标识、已打开格、旗／问号状态、首次开格坐标、开始／结束时间、完整用时、修订号和结算去重标识。全局偏好与个人纪录分开存放。
- `ready` 存档没有雷图或开始时间；`playing` 存档必须已有固定雷图。恢复重新校验雷数、格子集合、数字、标记互斥、阶段和胜负一致性；数字可由同一雷图重算，不重新随机生成。
- 正常退出／返回大厅保留最近成功保存的进度；通过[共通练习导航](../../../app/platform/practice-navigation.mjs)离开。大厅主动再次进入才恢复，不因浏览器前进／后退自动重开或恢复旧事件监听。
- 保存失败时明确显示“仅本次游玩，进度无法保存”，允许在当前页继续；不得显示保存成功或用残缺快照覆盖原存档。离开前说明未保存进度会丢失。
- 损坏或未知版本存档保留原记录并提示无法恢复，提供明确重新开始；不能自动清空、降低难度或把异常存档算作失败。新规则另定版本，旧局仍按原版恢复，无法支持时明确拒绝。
- 同一浏览器同一难度仅一个标签页可以写入存档。第二页先只读；明确接管后旧页停止操作和写入，迟到动作不能覆盖新修订。锁不可用时按页内临时局说明，不静默采用最后写入者获胜。
- 刷新、暂离或网络中断不影响本机已保存的雷图；关闭后续入仍按第 5 节计算离开用时。是否具备完整离线页面缓存由后续接入计划验证，不把规则可离线误写成首次无网络也一定能加载网页。

## 8. 状态合同与共通能力接入

### 8.1 规则状态与不变量

- 核心行动为 `reveal / mark / chord / new-game`；参数只包含当前局身份、预期修订、动作编号和目标坐标／难度，不从界面读取“这里是雷”作为判断依据。
- 每次行动先校验局身份、阶段、坐标、标记与修订，再一次性固定打开集合、胜负、时钟和结算结果。相同动作编号只生效一次；跨局旧动作拒绝，不能落到新局同一坐标。
- 布雷后始终满足：格子总数＝雷格数＋非雷格数，雷格数等于该档雷数；编号唯一且坐标不越界；非雷数字恰为八邻雷数；打开集合不重复；旗与问号互斥，且不与已打开集合相交。
- `playing / won` 不存在已打开地雷；`lost` 必须有有效触雷格。胜利要求打开全部非雷格，失败不得同时写成胜利。开局前标记、计数负数和安全格误插旗都属于合法状态。
- 本机展示状态包括焦点、滚动、缩放、按下预览和输入模式；它们不改规则结果，不作为恢复时重新执行的动作。

## 9. Step 0 资源与实现前门槛

- **棋盘资源**：16 类基础显示状态——未开、按下预览、空白、数字 1～8、旗、问号、雷、红底触雷、错误旗。聚焦框、标记模式高亮和不可操作样式作为叠加效果定义。
- **头部资源**：4 种表情（普通、紧张、胜利、失败）；计数器数字 0～9 与负号共 11 种字符，可代码绘制，不要求逐字符图片。三档参数使用同一套资源。
- **音效**：开格、标记、胜利、失败四种语义，优先映射既有合成音效；大面积展开不逐格播声。资源加载失败保留数字、文字标记及结果说明。
- **制作方式**：CSS／SVG／文本与自制声音，不依赖 AI 插画、付费素材或 Windows 原始位图。资源版本与规则版本分别管理。
- **代表样板**：初级全盘、高级 30×16 密集盘、数字 1～8、负数计数、问号／错误旗、触雷／胜利结果，及手机横屏可滚动棋盘。
- **可操作小样**：首次数字开局、空白展开、左右双键、问号循环、错误旗快速开格、长按取消与滚动、重开确认、刷新恢复。验证先于完整接入，不把样板当作已可玩成品。
- **通过条件**：最小尺寸下格子与标记可读；触摸能区分点按／长按／滚动；头部出口不被大棋盘遮挡；一次手势只产生一次动作；计时、固定雷图和保存失败反馈符合本文。
- **当前状态**：资源未制作，Step 0 未开始，技术计划未编写；资源、浏览器和真机验收均待完成。

## 10. 完整例子与验收条件

### 10.1 玩家规则例子

1. **从开始到胜利**：选择初级 → 棋盘 81 格、估计雷数 10、计时 000 → 可先插旗但时钟不动 → 第一次打开未插旗格，固定 10 雷并开始计时 → 首格若为数字只开这一格，若为 0 则展开 → 继续开格并用标记辅助判断 → 第 71 个安全格打开且本次没有踩雷，立即胜利、停表并显示剩余雷旗 → 更新该档本机最佳或保留旧纪录 → 再来一局获得新的空白局。
2. **合法空白展开**：初级 `(0,0)` 的八邻范围内无雷，打开后为 0；展开所有与其连通且未插旗的 0 及边界数字。某个安全邻格此前误插旗则保持覆盖，不算已打开；随后取消旗也不自动打开它，须继续操作。
3. **不合法开旗格**：`(2,3)` 已插旗 → 玩家尝试打开 → 不执行，旗、雷图和已打开数量不变；若此前未首次开格，时钟仍为 0。取消旗后才可正常打开。
4. **正确快速开格**：已开数字 2 周围正好两面旗，且都是真雷 → 执行双键 → 打开其他未开邻格及空白展开，旗保留 → 根据最终安全格数量继续或胜利。
5. **数量不足不执行**：已开数字 2 周围只有一面旗 → 双键 → 给轻提示，不开任何格、不补旗、不暗示哪一格是雷；三面旗同样不执行。
6. **错误旗导致失败**：数字 1 周围有一面误插在安全格的旗，真正地雷仍未标记 → 双键符合数量前提 → 打开未标雷并失败。即使同次打开了最后一个未插旗的安全格，也不得判胜。
7. **标记不等于胜利**：初级已插 10 面旗，计数为 0，但仍有安全格未打开 → 继续游戏；再插一面显示 −1，仍不结束。打开全部 71 个安全格才胜利，不能要求把雷也左键打开。
8. **没有超时惩罚**：中级已玩到 999 秒 → 头部停留 999，内部继续计时，棋盘仍可操作 → 1050 秒完成时结果显示 1050 秒，不判超时失败。
9. **中途离开并恢复**：高级开始后 25 秒退出，离开 40 秒再继续 → 雷位、标记和已打开格与保存时相同，用时约 65 秒；不重新采样、不暂停离开用时，也不补播开格音。
10. **重开取消与确认**：进行中切换到没有存档的难度 → 弹窗说明离开当前局、该局保存进度仍可续入 → 取消则全部保留；确认则建立新难度的新局、清空新局时钟与标记，不把旧图缩放或截成新棋盘。目标难度已有进度时，继续与重新开始必须分别选择。

### 10.2 必须通过的验收

1. 三档尺寸、雷数和胜利阈值分别为 9×9／10／71、16×16／40／216、30×16／99／381；任意传入的非预设难度或尺寸组合拒绝。
2. 角、边、内部数字均按八邻计算；没有跨行邻接，0 展开不漏格、不重复、不穿过数字或旗。问号能被直接开格和展开清除。
3. 所有首次有效开格位置安全；有相邻雷的首次数字局合法。开局前标记不改变布雷候选；无效开旗格、问号切换不布雷。第一次展开后刷新保持完全相同雷图。
4. 标记三态循环、关闭问号、负数计数均正确；旗数等于雷数、所有雷已插旗都不能提前判胜。安全格误旗未打开时不能胜利。
5. 双键与双击每次最多执行一次快速开格；多旗／少旗无效，错误旗可踩雷；同动作触雷与打开最后安全格时只记失败。
6. 胜利自动显示剩余雷旗；失败区分触雷、其他雷、正确旗与错误旗。两种结果停表且棋盘只读；重复事件、刷新和恢复不会重复更新最佳。
7. 计时只从首次有效开格开始，999 不结束游戏；设置、后台、刷新及关闭后续入按经过时间一致。异常设备时钟不产生负值或最快纪录。
8. 每档本机保存和纪录隔离；新局、放弃和切换难度不误删其他难度数据。检查无存储权限、容量不足、损坏记录、未知版本和多标签接管，不覆盖其他标签的新修订。
9. 从实际大厅入口完成“新局 → 标记 → 开格 → 快速开格 → 胜／负 → 再来 → 退出 → 主动续入”，全过程不生成房间、聊天、正式战绩或账号积分。
10. 键盘可完成全局，右键菜单只在棋盘抑制；长按不追加开格、滚动不误标、双点不重复执行。方向键不把页面滚离当前格子。
11. 初级与高级分别检查电脑、手机短横屏和转向提示；高级局所有 480 格可达，滚动后命中坐标准确，头部计数和设置／退出仍可见。横→竖→横不重开、不停表、不改变状态。
12. 真实页面验证设置、规则、纪录清除、重开确认的单层切换，音效去重、静音、减少动态、读屏与资源失败替代；真实触摸和声音听感单独记待验，不以模拟视口代替。
